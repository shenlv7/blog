> 2006 年 7 月，多伦多大学的两篇论文几乎同时出现。一篇 28 页，讲怎么让有向概率图的后验重新变得可分解；一篇 4 页，把同样的算法套在一个四层编码器上，给出了一张让整个领域改变判断的对比图。它们解决的不是「梯度会不会消失」，而是一个更朴素的问题：**训练开始的那一组权重，凭什么值得信任。**

**读这篇要会**：反向传播与链式法则 / Sigmoid 单元和 logistic 回归 / 能量模型的基本写法（配分函数 Z 是什么、为什么它算不出来）/ 极大似然与 KL 散度的大意。

---

## 一、卡点：反传有了二十年，深度还是训不出来

1986 年的反向传播解决了信用分配（第 08 期）：给定一个目标函数，怎么把误差分摊到每一个权重上。这个算法对任意深度的网络都成立，数学上没有藏着「只能两层」的限制。但整个 1990 年代到 2000 年代前期，三层以上的网络在实务上基本被判了死刑，而判决书不是理论写的，是实验写的。

失效有三种，根子都在起点上。

**初始化太小。** Sigmoid 的导数上界是 0.25，权重矩阵的本征值再小一点，误差传到第 k 层就被乘了 k 次小于 1 的因子。前几层收到的梯度接近数值噪声，等于没在训练。这时网络的表现退化成「只有最后一层在学」，深度带来的表达力一点没用上。

**初始化太大。** 权重一大，隐藏单元的输入落进 Sigmoid 的饱和区，导数趋近 0，同样是梯度消失，而且这一层的输出对输入的微小变化不再敏感——它已经把信息压掉了。

**落进坏解。** 这是最要命的一种，因为它不报错。一个多层的自编码器从随机权重出发做重构训练，常常收敛到一个所有输入都映射到同一张图的解：训练集里所有图的平均。这个解在参数空间里是一个宽而深的坑，梯度下降滑进去就出不来。Hinton 与 Salakhutdinov 在 2006 年的 Science 论文里把这句话写得很直接：不做预训练，很深的autoencoder 永远只会重构出训练数据的平均值，即使把微调时间拉得很长。

同时期的另一条路——核方法——正在赢。1992 年的核技巧、1995 年的统计学习理论、1998 年的 SMO，把「分类」变成了一个凸优化问题：有唯一最优解、有泛化界、有几行代码就能跑的求解器。相比之下，深度网络是一个非凸、超参敏感、没有收敛保证的东西。1990 年代末到 2000 年代中期的机器学习会议里，神经网络论文的比例掉到了边缘位置，这不是审美问题，是投入产出比问题。

所以 2006 年摆在桌上的问题需要换个问法。原来的问法是：**怎么把深网络的非凸优化做好？** 这个问题二十年没答案。换成的问法是：**能不能先不把它当判别器训，先让它学会生成数据，用生成模型给判别模型提供起点？**

这个问法的好处是，它把一个「一起训所有层」的难题，切成了若干个「一次只训一层」的小问题。而小问题里，每一层都是两层的一个受限结构，可以用局部采样近似求解。

难点在于，为什么「逐层生成」是合法的。有向的信念网络里，给定可见层，隐藏层的后验不是因子化的——几个隐藏单元共同解释同一个观测时，会互相「抢功」，这叫 explaining away。后验不可分解，就没法单独采样、没法单独训练。Neural Computation 那篇论文的标题里那个词「complementary priors」就是冲着这个来的。

## 二、机制：把「不可解的后验」用一个无向层焊回去

### 2.1 受限玻尔兹曼机：只有两层，而且层内不连

先把零件讲清楚。受限玻尔兹曼机（RBM）是 Smolensky 在 1986 年提出的，当时叫 harmonium：一层可见单元 v、一层隐藏单元 h，层内没有连接，只有层间的对称权重 w。它的联合分布由能量函数定义：

$$
E(v,h) = -\sum_i b_i v_i - \sum_j c_j h_j - \sum_{i,j} v_i w_{ij} h_j
$$

$$
p(v,h) = \frac{1}{Z}\exp\big(-E(v,h)\big), \qquad Z = \sum_{v,h}\exp\big(-E(v,h)\big)
$$

那个 Z 是所有可能配置的求和，可见单元有 64 个就是 2^64 项，算不出来。但层内无连接带来一个非常有用的性质：**给定 v，各个 h_j 条件独立**。

$$
p(h_j=1\mid v) = \sigma\Big(c_j + \sum_i v_i w_{ij}\Big)
$$

同理 $p(v_i=1\mid h)=\sigma(b_i+\sum_j w_{ij}h_j)$。于是「采样」变成了一次向量化的 Sigmoid 加一次伯努利抽样，不需要任何近似推断。不可解的东西只剩一个：边缘似然 $p(v)$ 里的 Z。

### 2.2 对比散度：用一步 Gibbs 换掉配分函数的梯度

最大似然对权重的梯度有一个漂亮的形式：

$$
\frac{\partial \log p(v)}{\partial w_{ij}} = \langle v_i h_j\rangle_{\text{data}} - \langle v_i h_j\rangle_{\text{model}}
$$

第一项好算：把数据喂进去，取隐藏单元为 1 的概率。第二项是模型自己分布下的期望，也就是「模型幻想出来的图」上的期望，需要对模型做充分混合的采样，代价和算 Z 一样高。

Hinton 在 2002 年给出的近似（对比散度，CD）是：从数据出发只跑一步 Gibbs，拿重构出来的可见状态当作模型分布的样本。

$$
\Delta w_{ij} = \varepsilon\big(\langle v_i h_j\rangle_{\text{data}} - \langle v_i h_j\rangle_{\text{recon}}\big)
$$

这一步不对应任何精确的似然梯度，它优化的是另一个量（数据分布与一步重构分布之间的 KL 散度差）。工程上它够用：权重学到的是「数据里哪些像素和哪些特征同时出现」，而重构项负责把不属于数据的巧合扣掉。学习率小、批量小、多跑几轮，权重会自组织成边缘检测器、笔画检测器这类局部特征。

### 2.3 逐层堆叠：上一层的隐单元变成下一层的数据

这是全篇的核心动作。训好第一层 RBM 之后，把数据过一遍，取隐藏单元的激活概率 $\hat h = p(h=1\mid v)$，把这批实数当作第二层的「可见数据」，训第二个 RBM。再往上同理。三层栈就是三个贪心训练的两层模型，每次只解一个局部问题。

论文给出的理论支撑是「互补先验」：如果顶层两层构成一个无向的联想记忆（一个 RBM），并且从下往上的生成权重被选成与从上往下的识别权重的转置相关联，那么每一层的有向部分的后验就重新变成因子化的。换句话说，顶部的无向层吸收掉了 explaining away 的耦合，独立的后验又可用了。这样堆出来的模型是一个混合体：最上面两层无向、下面几层有向，论文把它叫深度信念网络（DBN）。

它给出的直接好处是「加一层不会变差」：只要每层特征数不减、初始化正确，每加一层都会提高训练数据对数概率的一个下界。这条性质对自编码器只在特定条件下成立（特征数递减时就失效），但贪心逐层仍然是预训练深自编码器非常有效的手段——这是 Science 那篇论文的实际用法。

### 2.4 展开与微调：预训练只是起点，不是答案

预训练完成之后，把权重「展开」成一个编码器加一个解码器：编码器用原权重，解码器用它们的转置。这时候整个网络是一个深自编码器，接着用普通反向传播做重构误差的微调，随机性去掉，全部换成确定性的激活概率。微调会改动权重，但改动幅度不大——论文的原话是，预训练让权重里的大部分信息来自对图像本身的建模，标签那一点点信息只用来做轻微调整。

下面这段是本机跑通的 demo，用 8×8 合成笔画图（横、竖、斜三种笔画随机摆放，8% 像素翻转）代替 MNIST，规模小三个数量级，看的是机制方向，不是对 2006 年数字的复现。

```python
class RBM:
    def __init__(self, nv, nh, lr=0.05, seed=0):
        g = np.random.default_rng(seed)
        self.W = g.normal(0, 0.01, (nv, nh)).astype(np.float32)
        self.bv, self.bh, self.lr = np.zeros(nv, np.float32), np.zeros(nh, np.float32), lr

    def ph(self, v):                     # p(h=1|v)：层内条件独立，一次矩阵乘
        return sig(v @ self.W + self.bh)

    def pv(self, h):
        return sig(h @ self.W.T + self.bv)

    def cd1(self, v0):                   # 一步 Gibbs，就是对比散度
        p0 = self.ph(v0)
        h0 = (rng.random(p0.shape) < p0).astype(np.float32)
        v1 = self.pv(h0)
        p1 = self.ph((rng.random(v1.shape) < v1).astype(np.float32))
        n = len(v0)
        self.W  += self.lr * (v0.T @ p0 - v1.T @ p1) / n
        self.bv += self.lr * (v0 - v1).mean(0)
        self.bh += self.lr * (p0 - p1).mean(0)
        return float(((v0 - v1) ** 2).mean())

    def fit(self, X, epochs, bs=64, tag=""):
        self.bv[:] = logit(X.mean(0))    # 偏置先对齐数据边缘分布，否则前几十轮都在学均值
        for ep in range(epochs):
            idx = rng.permutation(len(X))
            errs = [self.cd1(X[idx[i:i + bs]]) for i in range(0, len(X), bs)]
```

训练栈与展开后的微调（节选）：

```python
def pretrain(X, epochs=60):              # 逐层贪心：上一层隐单元概率 = 下一层数据
    Ws, acts = [], X
    for i, nh in enumerate(SIZES[1:]):
        r = RBM(acts.shape[1], nh, seed=11 + i)
        r.fit(acts, epochs)
        Ws.append(r.W.copy())
        acts = r.ph(acts)
    return Ws

enc = [w.copy() for w in Ws]             # 展开：解码器直接用编码器权重的转置
dec = [w.T.copy() for w in reversed(Ws)]
# 之后用 Adam 对重构 MSE 做反向传播，编码器与解码器各自更新
```

三行重构误差放在一起读：随机初始化的网络停在 0.0724，确实比「什么都不学、直接输出平均图」的 0.1295 好，但好的幅度说明它只学到了「哪几个像素平均而言偏亮」，没有学到笔画的结构；预训练之后掉到 0.0422，是基线的三分之一。第三组是这套方法的真实动机：只有 100 个标签时，预训练让同一个三层网络的准确率从 0.524 变成 0.770——在这条设定下，起点的质量比标签的数量更值钱。

### 2.5 它为什么有效，以及为什么今天不再必要

对「预训练到底在帮忙做什么」，当时有两种解释，后来的实验给出的答案更接近第二种。

一种是优化解释：预训练把参数放进了一个好的盆地，反向传播只需要在盆地里滑下去。另一种是正则解释：预训练相当于给网络加了一个强先验——权重必须先能解释输入数据的结构，标签只能在这个约束下微调。

Erhan 等人 2010 年在 JMLR 上做的分析（《Why Does Unsupervised Pre-training Help Deep Learning?》）把这两种解释分开检验，结论偏向正则：预训练带来的收益在微调阶段仍然存在，而且权重在微调中移动的幅度很小，说明收益不是「更好的初始点让优化跑得更远」这么简单。同一批实验还发现，随机的、非监督的初始化也能带来一部分收益，但不如真正的预训练稳定。

这套方法后来不再是必需品，原因不在理论上，在四个工程改进上：

- **激活函数**：2010–2011 年 ReLU 被重新拿出来用，正区导数恒为 1，深网络的前层不再天然地收不到梯度。
- **初始化**：Glorot 与 Bengio 在 2010 年给出的方差缩放初始化（Xavier），让每层的激活方差在随机初始化下就大致守恒；He 等人在 2015 年为 ReLU 做了对应版本。
- **正则化**：Dropout（2012）用随机的单元丢弃替代了「用无监督预训练提供先验」这个功能，代价低得多。
- **归一化**：Batch Normalization（2015）把每层的输入分布强行拉正，优化景观本身变平了。

到 2012 年 AlexNet 在 ImageNet 上赢下比赛时，配方里已经没有逐层预训练这一项了：随机初始化、ReLU、两块 GPU、Dropout，从头到尾监督训练。当年那句「深网络必须靠无监督预训练才能训」，在四年内从「共识」变成了「历史」。

不过「预训练」这个词没有死，它换了个位置回来了。2018 年的 BERT 与 GPT 做的也是预训练加微调，但目的完全不同：不是绕开优化困难，而是把无标注文本变成监督信号，学一个可迁移的语言表示。同一个词，2006 年解决的是「能不能训」，2018 年解决的是「标注不够怎么办」。

| 生态 | 2007–2011 年逐层预训练的 RBM/DBN 成为深度网络的默认配方，蒙特利尔的 Theano（2008）等工具链围绕这类模型生长 |

需要把 1.2% 这个数字的性质说清楚：它是「预训练 + 梯度最速下降 + 小学习率」的结果，不是一次调参竞赛的冠军。它证明的是这条路径能到竞争水平，而不是它比 SVM 天生更强。事实上论文里那几个百分点的差距，在随后几年被更好的激活函数和正则化以大得多的幅度抹平了——抹平的方向恰好是把预训练拿掉。

真正留下来的东西不是配方，是一个判断：**深度网络的性能下限由初始化决定，微调只能在这个下限之上做局部改善。** 2010 年之后的 Xavier、Kaiming 初始化，2015 年的残差连接，本质都在解决同一件事——把「起点」这件事从靠一个生成模型来兜底，变成能用公式算出来。

## 四、下一篇预告

2006 年证明的是「深可以训」，但没有回答「深有什么用」。当时的基准是 MNIST 和几个人脸、文档数据集，规模都在十万样本量级，深网络相对浅模型或 SVM 的优势是几个百分点，说服力有限。

转折点在 2012 年：一个叫 ImageNet 的数据集把类别数推到 1000、训练图推到 120 万张，两块消费级 GPU 提供了一百多倍于 CPU 的卷积吞吐。第 12 期讲 AlexNet——为什么同一套反向传播、同一类卷积结构，在 2006 年只能赢几个百分点，在 2012 年能把 top-5 错误率从 26.2% 打到 15.3%，以及那两块 GTX 580 的 3GB 显存如何决定了网络必须被切成两半、分别放在两张卡上训练。
