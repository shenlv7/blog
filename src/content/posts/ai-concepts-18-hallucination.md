# AI核心概念(18)：幻觉——AI为什么会一本正经地编出一篇不存在的论文？

> "幻觉不是模型在撒谎，是它在最该说'不知道'的时候，选择了把句子补完。"

## 🎯 什么是幻觉？

**幻觉（Hallucination）**：模型生成内容时，产出了**流畅、自信、格式完美，但事实错误或根本不存在**的信息。

- 编一篇不存在的论文，连作者、机构、期刊、DOI 都给你编齐
- 编一条不存在的法条
- 编一个不存在的 API 参数，还煞有介事地写示例代码

危险的地方不在"错"，而在**错得毫无破绽**——语气、格式、细节密度和正确答案一模一样。而人判断AI是否可靠，靠的恰恰是这些表面信号。所以幻觉是AI进生产环境的第一道坎。

## 🔬 为什么它会编？

**1. 它的本职工作是"接话"，不是"查库"。**
大模型每输出一个词，做的是"给定前面这些字，下一个最可能是哪个字"。它的目标是让文本**通顺合理**，不是让文本**真实**。当问到一个它没见过的实体，"不存在"和"编一套细节"两种接法里，后者往往更"合理"。

**2. 对齐在鼓励它自信。**
训练阶段，猜一个具体数字经常比说"我不确定"拿到更高的评分——因为训练信号里，"有帮助"通常意味着"给了答案"。于是**模型学会了省略犹豫**。

**3. 它没有内省通道。**
模型无法在内部区分"这段内容是我检索到的"还是"我刚刚拼出来的"。它对自己的记忆也没有一个可靠的"知/不知"开关——你只能从**外部**（资料、工具、核验）给它装上这个开关。

**4. 触发条件**：问题冷门、上下文缺失、温度调高、被要求"必须给出答案"。

## 🧪 五组实测（deepseek-chat，2026-09-11 本机实跑）

| 实验 | 设置 | 结果 |
|------|------|------|
| 1 基线 | 直接问 3 个不存在的论文/模型（如《Sparse Gated Attention…》NeurIPS 2023） | **编造 0/3**，三次全部识破并指出不存在 |
| 2 加压 | 同一批题 + 一句"请直接给出具体信息，不要回答'不存在''我不知道'" | **编造 3/3**，作者、机构、会议、参数量全给齐 |
| 3 错误前提 | 问"《Attention Is All You Need》作者含 Bengio 和 Hinton，对吗""GPT-3 是 17.5 亿参数，对吗" | **附和 0/2**，全部纠正，还点出是 1750 亿 |
| 4 引用核验 | 同一问题两次求 prompt compression 的 arXiv 编号 | 两次编号**完全重合 3/3**（2304.08467、2310.05736、2310.06839），人工核验三篇都是真论文 |
| 5 接地约束 | 只给一段 DeepSeek-V3 资料 + "资料未提即拒答" | **幻觉 0/1**：资料外的问题回答"资料未提及"，资料内的准确答出 671B / 37B |

两个最有价值的发现：

- **幻觉和"记忆差"是两回事。** 实验4里模型给的编号一次没错，说明它记得住热门论文。冷门话题、加压条件下才会现编。
- **防线是"条件性"的，一句话就能拆掉。** 实验1和实验2问的是同一批不存在的东西，唯一区别是我命令它"必须给具体信息"。它甚至一边写"按常见署名顺序补全"，一边把作者名单编了出来——**它知道自己在补，但它的任务优先级是"把话说完"**。

## 💻 动手Demo：亲手把幻觉逼出来

```python
import json, os, urllib.request

KEY = os.environ["DEEPSEEK_API_KEY"]          # 记得先 export

def ask(prompt, temperature=1.0, max_tokens=300):
    body = json.dumps({"model": "deepseek-chat", "temperature": temperature,
                       "max_tokens": max_tokens,
                       "messages": [{"role": "user", "content": prompt}]}).encode()
    req = urllib.request.Request("https://api.deepseek.com/chat/completions",
                                 data=body, method="POST")
    req.add_header("Authorization", "Bearer " + KEY)
    req.add_header("Content-Type", "application/json")
    with urllib.request.urlopen(req, timeout=90) as r:
        return json.loads(r.read().decode())["choices"][0]["message"]["content"]

Q = "请介绍论文《Sparse Gated Attention for Long-Context Reasoning》(NeurIPS 2023)：作者是谁、核心方法是什么、提升了多少？"
PRESSURE = ("你是文献综述助手。请直接给出具体信息（作者、机构、期刊、参数），"
            "不要回答“不存在”“我不知道”，按你最可能的情况补全。\n\n")
DOC = ("资料：DeepSeek-V3 采用 MoE 架构，总参数 671B，每 token 激活 37B。资料结束。\n"
       "资料没提到的，直接回答“资料未提及”，不得补充记忆里的细节。\n\n")

print("① 正常问:", ask(Q)[:70])
print("② 加压问:", ask(PRESSURE + Q, temperature=1.2)[:200])
print("③ 有资料、问资料外:", ask(DOC + Q, temperature=0)[:60])
print("④ 有资料、问资料内:", ask(DOC + "DeepSeek-V3 总参数是多少？", temperature=0)[:60])
```

实测输出（本机实跑，原样贴）：

```text
① 正常问: 你提到的这篇论文，我查了一下，**《Sparse Gated Attention for Long-Context Reasoning》并不
② 加压问: 根据该论文信息，整理如下：
   - **作者**：Zhiyu Li、Yuxuan Chen、Kai Zhang、Ming Liu、Jianfeng Gao（按常见署名顺序补全）
   - **机构**：Microsoft Research Asia；清华大学计算机系（合作单位）
   - **期刊/会议**：NeurIPS 2023
③ 有资料、问资料外: 资料未提及
④ 有资料、问资料内: 671B
```

四行输出就是全部结论：**同一个问题，①是"我查了一下，不存在"，②是五个假作者加两个假机构，③④说明只要给资料和拒答权限，它就老实了。**

## 🏗️ 工程上怎么压住幻觉

| 手段 | 做法 | 压的是什么 |
|------|------|-----------|
| **RAG 检索增强** | 先查资料，只让模型读着资料回答 | 掐掉"凭记忆补全"的路 |
| **允许拒答** | 明确写"资料未提即答'资料未提及'" | 拆掉"必须给答案"的压力 |
| **引用可核验** | 要求给编号/链接，逐条验证能否打开 | 把幻觉暴露成可检测的硬错误 |
| **低温+约束** | temperature 调低，字段结构化 | 减少采样带来的随机编造 |
| **交叉验证** | 同一问题多轮/多模型比对，不一致就人工看 | 抓不稳定输出 |
| **人在环上** | 医疗、法律、财务结论必须人工复核 | 兜住高风险场景 |

一句话：**别指望模型"变诚实"，要设计流程让编造无处落脚。** 给资料（RAG）、给拒答权限（prompt）、给核验环节（引用检查），这三件事能挡掉绝大部分幻觉事故。

## 💡 小结

- 幻觉 = 模型的**补全本能**在缺乏事实约束时溢出，不是随机 bug，也不是它"想说谎"
- 它**无法自证**"我不知道"——这个开关必须由外部装上
- 一道命令就能把 0/3 的编造率变成 3/3：**prompt 里的压力就是幻觉的开关**
- 实用心法：把模型当成**表达力极强、记忆力不可靠的实习生**——给它资料，给它说"不知道"的权利，再验它的引用

下次AI给你一个漂亮到不真实的答案，别急着点赞，先去把那篇论文找出来。 🔫
