# AI核心概念(58)：激活量化——8 个通道把 255 个格子吃掉了

> 同一个矩阵乘，同一个对称 INT8，只换"尺子量在谁身上"：量权重是 **42.71 dB**，量激活是 **24.54 dB**。
>
> 差 18.2 dB，按每 bit 6.02 dB 算，等于 **3 个 bit 的钱没花出来**。而它并不是均匀丢的：512 个输入通道里有 8 个的峰值是其余通道中位数的 **50.6 倍**，per-tensor 的 scale 由这 8 个通道定死 → 剩下的 504 个通道在 255 个格子里实际只落到 **9 个**，**38.4%** 的激活值直接被压成 0。
>
> 更值得记的是这两个失败：我第一版用高斯激活，跑出"W8A8 37.95 dB、平滑只赚 0.48 dB"，差点得出"激活量化几乎免费"的结论；第二版换了真实结构，同一个方案的收益从 0.48 dB 变成 **12.98 dB**。而我第一版的预测公式（用全局 crest factor 相加）预言最优 α=0，实测是 **0.6**——错在拿"权重每行一把尺"的粒度去估"每列离群"的代价。修成按粒度逐项累加的误差预算后，11 个 α 的预测误差全程 **≤ 0.1 dB**，最优点也对上了。
>
> 边界先钉死：这是**合成激活 + 单层矩阵乘 + 无校准集 + 无 kernel 实现**的机制实验，不是真实 LLM 的精度实测。SmoothQuant 论文里那句"几乎无损"能不能落到你的模型上，取决于你的激活里到底有没有这种离群结构——这篇给的是**怎么验、代价怎么算**，不是"照抄 α=0.5 就能上线"。

**读这篇要会**：对称量化的 scale / step / round-to-nearest；矩阵乘法；dB 形式的信噪比（SQNR）；softmax 之前的 logits 大致是什么形状。会 Python 和 numpy 就够，不需要 GPU。

## 🎯 先把"量化谁"拆成三件事

第 21 篇量化的是 **W**（权重矩阵）：离线做一次，压完模型文件就小了，推理时反量化能提前融进 kernel。第 56 篇量化的是 **KV cache**：推理时每层、每个 token 现场算出来的 K 和 V，不落盘，只在显存里活着。这篇量化的是 **激活 X**：每一层、每一批输入前向进来时才产生的东西——它既不在文件里，也没法离线预计算。

三者的难度不在一个量级，原因只有一个：**权重可以在离线把整张矩阵看一遍，激活不能。**

| 对象 | 何时可见 | 能用的粒度 | 主要风险 |
|---|---|---|---|
| 权重 W | 离线，一次性 | per-channel / 分组 / 4bit 甚至 3bit 都行 | 小于 1% 的权重被压成 0（第 21 篇：89.74%） |
| KV cache | 推理时，历史全可见 | per-token 或 per-channel，可以分组 | 长上下文下 99.6% 元素被抹掉（第 56 篇） |
| 激活 X | 推理时，只有当批数据 | 通常 per-tensor 或 per-token（要看 kernel 支持哪种） | **几个通道的离群值就能吃掉大半量程** |

命名读法：`W8A16` = 权重 8bit、激活 16bit（fp16/BF16 视实现）；`W8A8` = 两侧都 8bit，这才真的省下矩阵乘的带宽；`W4A16` 是生产上最常见的一档（GPTQ / AWQ 都是这条路）。

为什么 `W4A16` 比 `W8A8` 更常见？不是因为 4bit 权重比 8bit 激活更准——下面实验里正好相反（W4A16 = 17.49 dB，比 W8A8 平滑后的 37.78 dB 差得多）。**是因为"改权重的粒度"是免费的，"改激活的粒度"要改 kernel。** 权重按输出通道一把尺，编译器可以把它折进反量化；激活按通道一把尺，就变成逐通道的乘加，等于把省下的带宽又花回去。这条约束比任何精度论战都更能解释工业界的选型。

## 🔬 实验设置，以及我第一版为什么是废的

| 项 | 设置 |
|---|---|
| 规模 | 512 → 512 的矩阵乘，batch = 64 token，单层 |
| 激活结构 | 标准正态 + **8 个通道 ×40 倍**（跨 token 稳定，模仿 LLM.int8() 观察到的通道级离群） |
| 权重结构 | 正态 /√d + 6 个输出通道 ×3 倍（权重本身的重尾比激活温和得多） |
| 量化 | 对称、round-to-nearest、无残差、无分组；bits=16 时是恒等映射 |
| 指标 | SQNR(dB)、相对 L2 误差、cos；单种子看分布，5 个种子报 mean±std |
| 零假设 | bits=16 时端到端误差必须严格为 0；平滑变换 X/s、W·s 必须是恒等重参数化 |

零假设两项我都验了：`16bit 端到端 max|Y−Y16| = 0.000e+00`，平滑变换在 α∈{0, 0.5, 1} 下 `max|Xs·Ws−X·W|` 都在 1e-14 量级（fp64 舍入）。**如果你改这份代码，先跑这两条**——我见过太多"量化实验"其实测的是自己写错的 scale。

第一版为什么是废的：我用 `numpy.random.randn` 生成激活，**一点离群都不加**。跑出来 W8A8 per-tensor 有 **37.95 dB**，套上平滑只涨 **0.48 dB**。那一刻的结论会是："激活量化几乎无损，SmoothQuant 是一个解决不存在的问题的方案"。

这个结论在纯高斯世界里**是对的**——Crest factor（峰值/均方根）只有 13.07 dB，8bit 的理论上限 6.02×8+1.76 = 49.9 dB，减掉 13 dB 还剩 36.8 dB，和实测对得上。错的是世界模型：真实 LLM 的激活不是高斯的，它是**少数通道上稳定的大值**（Dettmers 等人在 LLM.int8() 里发现，arXiv:2208.07339，这些离群维度在超过 6.7B 的模型里普遍存在，而且和特定 token 强相关）。加上 8 个 ×40 的通道之后，crest 从 13.07 dB 跳到 **28.04 dB**，整个实验的结论就翻了。

## 📊 实验A：18.2 dB 的差距，不在位宽上

| 方案 | SQNR(dB) | 相对 L2 | cos |
|---|---|---|---|
| W8A16（只量权重，per-channel） | **42.71 ± 0.11** | 0.007 | 1.0000 |
| W8A8 per-tensor | 24.54 ± 0.60 | 0.059 | 0.9982 |
| W8A8 per-token | 29.40 ± 0.13 | 0.034 | 0.9994 |
| W8A8 per-channel（激活也按通道） | 40.33 ± 0.13 | 0.010 | 1.0000 |
| W8A8 平滑 α=0.5 | 37.06 ± 0.52 | 0.014 | 0.9999 |
| W4A16（只量权重，per-channel） | 17.49 ± 0.10 | 0.133 | 0.9912 |
| W4A8 平滑 α=0.5 | 13.64 ± 0.47 | 0.208 | 0.9786 |
| W4A8 per-tensor | 12.65 ± 0.06 | 0.233 | 0.9726 |

四行话：

- **权重 8bit 基本免费**（42.71 dB，cos 到小数点后四位还是 1），激活一压掉 18.2 dB。同一个格式、同一个位宽，差别全在"数据长什么样"。
- **per-token 只救回 4.9 dB**。这是个容易误判的点：直觉是"每个 token 自己一把尺，离群不就管住了"，但离群是**按通道**的——同一行里那 8 个通道依然是峰值，per-token 的尺子照样被它们撑到 40 倍，其它通道照样只剩 9 个格子。粒度选错方向，等于没选。
- **per-channel 激活 40.33 dB，几乎追平只量权重**。这是精度的上界，也是工程的死路：它要求 kernel 按通道做乘加，省下的字节又还回去。
- **平滑 α=0.5 拿到 37.06 dB，离"免费"只差 5.6 dB，但用的是 per-tensor kernel**。这就是 SmoothQuant 的全部卖点：不改硬件路径，把误差搬走。

W4 那一档值得单看一眼：只量权重 17.49，激活也压到 8bit 就 13.64——**位宽越紧，激活这一刀越疼**。这也解释了为什么 W4 的工程实践几乎全押在 A16 上。

## 🧮 实验B：255 个格子，普通通道只用到 9 个

定义式先写清楚。均匀量化步长 Δ、量化噪声方差 Δ²/12，信号是方差 σ²，于是

```
SQNR_dB = 6.02·b + 1.76 − 20·log10( peak(x) / RMS(x) )
```

其中 `peak(x)` 是这一把尺子管的范围里的最大绝对值，`RMS(x)` 是均方根，两者之比就是 **crest factor**。这个式子说明：**位宽 b 是名义值，crest factor 是折扣。** 每多 6 dB 的 crest，等于白丢 1 bit。

实测逐项对：

| 量 | 值 |
|---|---|
| 激活 crest factor | 28.04 dB |
| 公式预测（激活单独，8bit） | 21.88 dB |
| 实测（激活单独，8bit） | 24.86 dB |
| 8bit 的 255 个格子中，普通通道实际用到 | **9 个**（≈3.2 有效位） |
| 被压成 0 的元素占比 | **38.4%** |
| 离群通道峰值 / 中位通道峰值 | 130.3 / 2.58 = **50.6 倍** |
| per-tensor 的 step | 1.03σ（普通通道每 1 个标准差只有 1 格） |

公式比实测**悲观 3 dB**，原因值得说：式子里拿"全局 RMS"当信号能量，但这批数据里大部分能量集中在被量得很准的那 8 个离群通道上，误差主要落在贡献小的通道里。所以这个公式是**误差上界**，用来排序和估算预算合适，用来报绝对精度会偏保守。

另一个数：如果尺子按正常通道的峰值来定，step 会是 0.0205 而不是 1.03——**50 倍**，即 34.1 dB ≈ 5.7 bit。而实测只丢了 3 bit。差的那 2.7 bit，正是"被丢的位主要丢在能量小的通道上"省回来的。**所以"有效位宽"没有单一换算系数，它依赖误差和信号的能量分布。** 谁跟你说"这个模型量化后等价 5.5 bit"，你应该问他这个数是怎么在输出上量的。

## 🔬 实验C：α 不是玄学，预算是能算的

SmoothQuant（Xiao 等人，ICML 2023，arXiv:2211.10438）的做法是**逐输入通道平移难度**：给每个输入通道 j 一个缩放因子

```
s_j = max|X_j|^α / max|W_j|^(1−α)      X' = X / s,  W' = W · s
```

数学上 `X'·W' = X·W`，一分钱不差（上面验过 1e-14）。它只是把"激活那边太尖"的问题，按 α 分一部分给权重——而权重是按行量的，多尖都吃得下。

问题只剩 α 取多少。我第一次的写法是"让两侧 crest 之和最小"，结果预言 **α=0**（也就是完全不平移），实测最优 0.6。原因：权重是 per-channel 量的，用全局峰值算它的噪声，把 W 的惩罚夸大了 20 多 dB。

正确的预算是逐项按粒度累加。输出元素 `y_bi = Σ_j x_bj·w_ij`，误差来自两侧：

```
noise_out,i ≈ (Δx²/12)·Σ_j w_ij²          # Δx 由激活的粒度决定（per-tensor = 全局峰值）
            + Σ_j (Δw_i²/12)·E_b[x_bj²]   # Δw_i 由该行峰值决定（per-channel）
SQNR = 10·log10( E[y²] / mean_i(noise_out,i) )
```

拿这个预算扫 α：

| α | crest(X') | crest(W') | 预算预言 | 实测 SQNR | 差 |
|---|---|---|---|---|---|
| 0.0 | 29.29 | 12.68 | 21.52 | 21.62 | +0.10 |
| 0.1 | 28.93 | 16.40 | 25.23 | 25.20 | −0.03 |
| 0.2 | 28.40 | 20.03 | 28.83 | 28.80 | −0.03 |
| 0.3 | 27.57 | 23.50 | 32.19 | 32.24 | +0.05 |
| 0.4 | 26.25 | 26.68 | 35.07 | 35.02 | −0.05 |
| 0.5 | 24.31 | 29.41 | 37.09 | 37.13 | +0.05 |
| **0.6** | 21.74 | 31.55 | **37.73** | **37.78** | +0.05 |
| 0.7 | 18.68 | 33.06 | 36.82 | 36.81 | −0.01 |
| 0.8 | 15.32 | 34.07 | 34.71 | 34.73 | +0.02 |
| 0.9 | 11.79 | 34.76 | 31.92 | 31.89 | −0.03 |
| 1.0 | 8.15 | 35.25 | 28.77 | 28.74 | −0.03 |

11 个点，预测误差全在 **±0.1 dB** 内，最优点也一样是 0.6。这张表本身就是结论：**α 不需要网格搜索，你需要的是一个按粒度写对的误差预算。**

两个极端都不好，原因对称：α=0 是"什么都不搬"（21.62，离群全留在激活侧）；α=1 是"全搬过去"（28.74，W' 的 crest 涨到 35.25 dB，权重开始被自己的离群值反噬）。**最优 α 是两侧 crest 的均衡点，而这个均衡点由数据决定**——论文里常见的 0.5 是默认值，我这批数据是 0.6，换模型必须重扫。这条比任何固定配方都重要。

## 🧪 实验D：没有离群值的时候，全篇结论反转

| 激活结构 | crest | W8A8 per-tensor | 平滑 α=0.6 | 平滑收益 |
|---|---|---|---|---|
| 纯高斯（无离群通道） | 13.07 dB | 37.95 dB | 38.43 dB | **+0.48 dB** |
| 8 通道 ×40 | 28.04 dB | 24.80 dB | 37.78 dB | **+12.98 dB** |

同一份代码，只改激活里的离群结构，平滑的收益差 **27 倍**。这说明平滑赚的钱不是"算法变聪明了"，而是**离群税的减免**——没有离群，就没有免税额度。

所以看到"我们这套量化在 XX 模型上几乎无损"时，第一个该问的不是位宽，而是：**那个模型的激活里有没有这种通道级离群？校准集有没有覆盖到它？** 离群值和特定 token 强相关（LLM.int8() 的结论），校准集里没有长上下文、没有特殊符号，你的 max 就是错的 max，尺子从头到尾都是错的。

## 🏗️ 实验E：三层叠起来——我猜错了

我预期误差层层放大：24 → 17 → 11 dB。实测（每层都做 W8A8 per-tensor，一路传下去）：

| 出口 | SQNR | 该层输入 crest |
|---|---|---|
| 第 1 层 h1 | 23.64 dB | 29.42 dB（原始激活） |
| 第 2 层 h2 | 23.31 dB | 21.99 dB |
| 第 3 层 Y3 | 22.68 dB | 21.46 dB |
| 对照：三层只量权重，激活保 fp16 | **37.43 dB** | — |

**平的，不是崩的。** 原因：线性层把输入通道级的离群洗掉了——crest 从 29.4 dB 降到 22.0 dB，因为每个输出元素都是 512 个通道的加权和，单个通道的尖峰被平均掉；而每层重建的量化误差量级差不多，所以误差在层间近似**相加**而不是**相乘**。没有残差回路把它滚起来。

这条要小心地读：真实 Transformer 有 residual、LayerNorm、注意力、激活函数，误差路径完全不同，**不要把这个"平"搬到真实模型上**，也不要把它读成"层数多了不会更差"。它的价值是方法论上的一句提醒——想说"层层放大"，先测 crest 在层间怎么变，别假设。

## 💻 可运行的最小复现

完整脚本（含 α 扫描、5 种子统计、三层实验）在演示文件里，以下保留核心 60 行，numpy 直接跑：

```python
import numpy as np
D, B, OUT_CH, OUT_MAG = 512, 64, 8, 40.0

def quant(x, bits, axis=None):
    if bits >= 16:
        return x.copy()
    amax = np.max(np.abs(x)) if axis is None else np.max(np.abs(x), axis=axis, keepdims=True)
    step = np.where(amax / (2 ** (bits - 1) - 1) == 0, 1.0, amax / (2 ** (bits - 1) - 1))
    return np.round(x / step) * step

def sqnr(ref, got):
    n = np.sum((ref - got) ** 2)
    return np.inf if n == 0 else 10 * np.log10(np.sum(ref ** 2) / n)

def crest(x):
    return 20 * np.log10(np.max(np.abs(x)) / np.sqrt(np.mean(x ** 2)))

def smooth(x, w, alpha):
    s = np.max(np.abs(x), axis=0) ** alpha / (np.max(np.abs(w), axis=0) ** (1 - alpha) + 1e-12)
    return x / s, w * s, s

def budget(x, w, bx=8, bw=8):
    """按粒度逐项累加，不用全局 crest 近似"""
    dx = np.max(np.abs(x)) / (2 ** (bx - 1) - 1)                    # 激活 per-tensor
    dw = (np.max(np.abs(w), axis=1) / (2 ** (bw - 1) - 1)).ravel()  # 权重 per-row
    mx2 = np.mean(x ** 2, axis=0)
    noise = (dx ** 2 / 12) * np.sum(w ** 2, axis=1) + (dw ** 2 / 12) * np.sum(mx2)
    return 10 * np.log10(np.mean((x @ w.T) ** 2) / np.mean(noise))

rng = np.random.default_rng(0)
X = rng.standard_normal((B, D)); X[:, rng.choice(D, OUT_CH, replace=False)] *= OUT_MAG
W = rng.standard_normal((D, D)) / np.sqrt(D)
W[rng.choice(D, 6, replace=False)] *= 3.0
Y = X @ W.T

assert np.max(np.abs(Y - quant(X, 16) @ quant(W, 16).T)) < 1e-9        # 零假设
print(f"crest = {crest(X):.2f} dB")
print(f"W8A16 {sqnr(Y, quant(X,16) @ quant(W,8,axis=1).T):6.2f} dB   "
      f"W8A8 {sqnr(Y, quant(X,8) @ quant(W,8,axis=1).T):6.2f} dB")

for a in (0.0, 0.5, 0.6, 1.0):
    Xs, Ws, _ = smooth(X, W, a)
    got = quant(Xs, 8) @ quant(Ws, 8, axis=1).T
    print(f"alpha={a:.1f}  预算 {budget(Xs, Ws):6.2f}  实测 {sqnr(Y, got):6.2f}")
```

跑出来的前三行应该是 `crest = 28.04 dB`、`W8A16 42.58 dB`、`W8A8 24.80 dB`，和上面的表对得上（小数点后两位会随种子变）。

## 🧭 工程口径，以及这篇不能证明什么

生产上实际怎么选，按优先级：

1. **能选 W4A16 就选 W4A16**。GPTQ（arXiv:2210.17323）、AWQ（arXiv:2306.00978）都在这一档，省的是权重带宽，激活不动，风险可控、kernel 成熟。
2. **要 W8A8，就必须处理离群**。两条路：SmoothQuant 式平滑（改权重系数，标准 INT8 GEMM），或 LLM.int8() 式混合分解（离群维度走 fp16，代价是 kernel 分支和一部分速度）。**没有第三条路能"什么都不做"还拿到 per-channel 激活的精度。**
3. **校准集是尺子的来源**。max 从校准集来，校准集漏了长上下文 / 特殊 token，你的 max 就小，clip 掉的就是真实推理时最尖的那批值。这一条比 α 取多少重要得多。

**这篇不能证明什么**：

- 不是真实 LLM 实测。没有预训练模型、没有校准集、没有 GPU，激活是合成的"正态 + 8 个 ×40 通道"，真实模型的离群结构比这复杂（不同层不同、和 token 位置相关、还会随序列长度变化）。
- 没有 kernel 实现。所有"per-channel 激活不可用"的论断来自硬件/编译器常识，不是我在本机测出来的（本机是 ARM，连 INT8 GEMM 都没跑）。
- 指标是 SQNR 和 cos，**不是准确率、不是 loss、不是下游任务分数**。SQNR 差 3 dB 在真实模型上是什么后果，这篇答不了。
- 单层 + 三层前馈，没有 residual / LayerNorm / attention。第 E 组那个"误差不放大"的结论只在合成前馈网络里成立。
- 平滑的 α 依赖数据分布，这篇给的 0.6 只对这批合成数据有效。

## 💡 结论四句

1. **同为 INT8，量权重 42.71 dB、量激活 24.54 dB。** 差别不在位数，在数据：激活有通道级离群，权重没有。
2. **8bit 名义位宽，普通通道实际只用到 9 个格子（≈3.2 bit），38.4% 的值被压成 0。** 一把尺子被 8 个通道的 50.6 倍峰值定死。
3. **粒度选错方向等于没选**：per-token 只救 4.9 dB（离群是按通道的），per-channel 才救回来（40.33 dB，硬件不认）。平滑用 per-tensor kernel 拿到 37.78 dB，这才是它的卖点。
4. **α 不用网格搜，用误差预算算**：按粒度逐项累加，11 个点的预测误差 ≤0.1 dB，最优点 0.6 和实测一致。而这一切的前提——激活里真有离群——必须先验证；没有离群的世界里，平滑只值 0.48 dB。
