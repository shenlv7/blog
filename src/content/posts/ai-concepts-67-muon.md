> Adam 管每个参数走多远，Muon 管整个矩阵往哪转。
> 前者的更新谱跟着梯度谱走，后者把谱直接压平成一条线——代价是你得重新理解「学习率」这个词的含义。

**读这篇要会**：矩阵的奇异值分解与条件数 / 动量 SGD 的一步更新 / 矩阵 Frobenius 范数。不需要 GPU，numpy 单机 47 秒跑完全部四组实验。

## 🎯 Adam 的盲区：它只看得见单个元素

Adam 的更新是逐元素的：$u_{ij}=m_{ij}/\sqrt{v_{ij}}$，每个坐标除以自己的历史梯度二阶矩，于是**每个元素获得等量级的步长**。这个性质在 2014 年是优点——它让不同量纲的参数共享一个学习率。但它对矩阵的整体形状一无所知。

后果是：如果当前这批梯度几乎都落在少数几个方向上（大 batch 平均后尤其明显，深度网络的梯度矩阵本来就是重尾的），Adam 会把大部分步长继续投给这几个方向，剩下的方向几乎不动。矩阵层面的有效秩因此长期上不去。本次实验里 Adam 训练出的更新矩阵 stable rank 只有 **35.9/64**，最大那个奇异值占了全部能量的 **13.0%**，W2 上更极端，**30.3%**。

Muon 换了个提问方式：不问「每个元素走多远」，问「这个矩阵应该朝哪个方向转」。

## 🔬 机制：动量先做正交化，再乘回尺度

三步，没有 SVD：

$$M_t=\mu M_{t-1}+G_t,\qquad W_t=W_{t-1}-\eta\left(0.2\sqrt{\max(n,m)}\cdot\mathrm{NS}(M_t)+\lambda W_{t-1}\right)$$

$\mathrm{NS}$ 是 Newton-Schulz 五次迭代，只用矩阵乘法逼近 $M(M^\top M)^{-1/2}$（即把奇异值全拉到 1 的部分）：

$$X_0=\frac{M}{\|M\|_F},\qquad X_{k+1}=aX_k+(bA+cA^2)X_k,\quad A=X_kX_k^\top$$

系数 $(a,b,c)=(3.4445,-4.7750,2.0315)$ 是 Muon 官方实现里的五次多项式，选它们是因为在 $[0,1]$ 上收敛快且溢出风险小。迭代数固定为 5，不做收敛判断——这决定了它可以写成静态计算图，塞进任何训练框架。

**缩放系数的来历值得算一遍**：正交化后 $O$ 有 $\min(n,m)$ 个奇异值都约等于 1，所以 $\|O\|_F^2\approx\min(n,m)$，元素均方根 $\approx\sqrt{\min/(nm)}=\sqrt{1/\max(n,m)}$。乘上 $0.2\sqrt{\max}$ 后，**更新 RMS 恒为 0.2，与矩阵形状无关**。这就是 Moonlight 论文说的「per-parameter update scale 调整」——不乘这一项，宽层和窄层的有效步长会差出几个数量级。

几何意义可以一句话说清：Bernstein 与 Newhouse 在 2024 年的分析里把两类优化器统一成「不同范数下的最速下降」——Adam 近似 $\ell_\infty$ 范数（最大坐标），Muon 近似谱范数（最大奇异值）。谱范数最速下降的解恰好是正交化后的梯度：所有方向步长相等，谁也别想垄断。

## 🏗️ 工程：省的不是计算，是优化器状态和调参

| 维度 | AdamW | Muon |
|---|---|---|
| 更新归一化 | 逐元素（$\ell_\infty$ 几何） | 逐矩阵（谱几何） |
| 优化器状态 | 一阶 + 二阶动量，2×参数量 | 仅一阶动量，1×参数量 |
| 每步额外算力 | 无 | 2D 层 5 次 $n\times n$ 级矩阵乘 |
| 适用参数 | 全部 | 仅 2D 隐藏层；embedding/输出层/偏置仍需 Adam |
| 学习率迁移性 | 跨层需各自调 | 形状无关的固定 RMS，跨层可共用 |

矩阵乘的额外开销在 $n\ll d$ 的层上可以忽略（每步 O(n³) 对比前向的 O(Bnd)），换来的是**优化器显存减半**：大模型训练里优化器状态常占显存的大头，1T 参数规模下这一项就是几百 GB 量级。分布式实现里，Moonlight 的做法是把梯度 reduce-scatter 后在本地做 NS，gather 回参数用 bf16，通信量是 AdamW 的 1～1.25 倍。

公开数据两条，都来自官方论文：**Moonlight**（Moonshot AI，arXiv 2502.16982）用 Muon 训了 3B/16B-A3B 的 MoE、5.7T token，缩放律实验显示达到同等 loss 只需 AdamW 约 **52%** 的训练 FLOPs，约 2 倍计算效率；代价是必须加 weight decay，并统一各参数形状的更新 RMS。**Kimi K2**（arXiv 2507.20534）在此基础上做了 MuonClip：Muon 比 AdamW 更容易出现注意力 logit 爆炸，于是每步之后按 $\eta=\min(\max_{i,j}q_i^\top k_j/t,\,1)$ 直接缩放 $W_q,W_k$，1T 总参数 / 32B 激活、15.5T token 预训练零 loss 尖峰；前 7 万步里 12.7% 的注意力头触发过裁剪，阈值 $t=100$。

## 💻 实测：谱被压平了，但小模型上不一定更快

实验分三块：先验证 NS 对病态矩阵的作用，再用 3 层 MLP（64→96→96→10，合成高斯簇）对比两个优化器并各扫学习率，最后加一个条件数 1000 的最小二乘作为反例。

```
== Newton-Schulz: 奇异值谱 ==
输入  : min=0.305 max=47.209 条件数=154.8
输出  : min=0.682 max=1.163 条件数=1.71
更新 RMS(未缩放)= 0.0882 (理论 sqrt(1/max(A,B))=0.1021)
stable rank 输入 41.2 -> 输出 62.0 / 64

== AdamW best lr=0.003 ==
  W1 更新矩阵 stable rank = 35.9 / 64 | top1 奇异值占比 = 13.0%
  W2 更新矩阵 stable rank = 31.8 / 96 | top1 奇异值占比 = 30.3%
  终值 val = 0.138

== Muon  best lr=0.005 ==
  W1 更新矩阵 stable rank = 62.1 / 64 | top1 奇异值占比 = 2.4%
  W2 更新矩阵 stable rank = 91.2 / 96 | top1 奇异值占比 = 1.8%
  终值 val = 0.154
  全部 lr 的终值 val: [(0.005,0.154), (0.01,0.192), (0.02,0.229), (0.04,0.536)]
```

三件事读得出来。**第一，正交化真的把谱压平了**：条件数 154.8 的病态矩阵进去，1.71 出来，stable rank 从 41.2 抬到 62.0（满秩 64）。第二次迭代后剩余的奇异值压缩主要来自输入本身接近秩亏——五次迭代的收敛域不是无限的，这也是官方实现要先除以 Frobenius 范数的原因。

**第二，Muon 的更新谱确实比 Adam 平得多**：stable rank 62.1 vs 35.9，最大奇异值能量占比 2.4% vs 13.0%。这是它能在大规模训练里省 token 的直接来源——每一步都在所有方向上推进，而不是反复加固已经很强的方向。

**第三，这个规模的收益是零**。各自扫学习率取最优后，验证损失 0.154 对 0.138，Muon 还略输。梯度噪声在 10⁵ 参数、batch=128 的量级上占主导，谱形状带来的差异被淹没。反例更直接：条件数 1000 的线性最小二乘里 Adam 也赢（终值 MSE 1.58e-1 vs 2.80e-1），因为二次型问题的最优预条件子是 Hessian 的逆，而逐元素归一在这个几何上恰好比「所有方向等步长」更接近它。

## 💡 边界在哪

Muon 的收益来自三个前提同时成立：**batch 足够大**（梯度谱的重尾性才明显）、**矩阵足够大**（NS 的开销占比才低）、**训练足够深**（层间谱差异才累积成有效秩差）。三条缺一条，省下的 FLOPs 会被调参成本和实现复杂度吃掉。

另外它是半个优化器：embedding、输出层、所有 1D 参数仍然得用 AdamW，一个训练脚本里要并存两套更新规则。稳定性也不是免费的——Muon 的固定 RMS 更新在注意力 logit 上会放大数值，Kimi K2 必须叠 QK-Clip 才敢跑 15.5T token。
