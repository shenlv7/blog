> 1986 年之后，网络能训了。但「训出来的这条线」和「最好的那条线」之间，当时既没有定义，也没有度量。

**读这篇要会**：矩阵乘法与内积 / 拉格朗日乘子与 KKT 条件的大意 / 什么叫凸函数 / 训练集误差与测试集误差的区别。

---

## 一、卡点：能训了，但没人能说清学到的是什么

1986 年的反向传播解决了信用分配——隐藏层没有目标值的问题，被链式法则绕过去了（第 08 期）。多层网络第一次可以按梯度训练，多层结构不再是摆设。但**能训不等于可信**，当时的训练过程有三个让工程师睡不着的特征。

第一，非凸。损失面上有局部极小、平台、鞍点，初始化和样本顺序都会改变最终落到的点。同一个任务跑两次，得到两个权重矩阵，都宣称自己在训练集上 100% 正确。

第二，没有泛化保证。训练误差下降为什么该带动测试误差下降？1980 年代的回答基本是经验：多训几个模型，看验证集。

第三，容量没有刻度。隐藏层加多少个单元算「刚好」？没人能给出一个数字和一条曲线，调参靠手感。

这些问题在 1980 年代末还不算致命，因为神经网络还有钱。到 1990 年代初，钱少了：专家系统的商业泡沫破裂，专用 LISP 机厂商接连倒闭，DARPA 收缩预算，AI 进入第二次寒冬。这场退潮的归因至今有争议——把责任推给单本著作或单次预算削减都站不住，它是市场、硬件路线和项目交付失败叠在一起的结果。

预算紧的时候，「再堆大一点试试」这条路走不通了。剩下的选择是换问题。

原来的问题是：**怎么造一个像大脑一样会学的东西？**
换掉以后的问题是：**给定 n 个样本、给定一个能度量的容量，怎么让测试误差的上界尽量小？**

第二个问题把「学习」从生物学问题拆成了优化问题加统计问题。1990 年代那条线——Vapnik 一系——就是沿着第二个问题走的，走出来的东西叫支持向量机。

| 换问题之前 | 换问题之后 |
|---|---|
| 模型要像神经元 | 模型只要是一个函数类 |
| 好坏看拟合得像不像 | 好坏看泛化上界 |
| 容量靠试 | 容量靠间隔/VC 维度量 |
| 解依赖初始化和顺序 | 解是凸问题的唯一最优解 |

## 二、机制：最大间隔、核、软间隔，三件事拼成一个算法

### 2.1 先把「最好的那条线」定义出来

线性分类器是 `f(x) = sign(w·x + b)`。能把训练集分开的 `(w, b)` 通常有无穷多组——这正是感知机顺序敏感的原因：感知机停在哪一组，取决于它最后看到的是哪个样本。

选哪一组？答案是：**离两类样本都最远的那一组**。把尺度归一化成 `y_i (w·x_i + b) ≥ 1`，两条支持面之间的距离就是 `2/‖w‖`。于是「找最宽的路」变成了一个标准形式：

```
min   ½‖w‖²
s.t.  y_i (w·x_i + b) ≥ 1,   i = 1..n
```

凸二次目标 + 线性约束 = 二次规划。**关键不在于这个式子好看，而在于它是凸的**：可行域是凸集，目标严格凸，最优解存在且唯一（w 唯一）。不依赖初始化，不依赖样本顺序，没有局部极小。1990 年代这一点比准确率更值钱——它是可复现的前提，也是一个团队能把模型交付出去的前提。

这个概念部分在 1965 年就做完了（Cortes 与 Vapnik 在 1995 年的论文里自己这么写），但当时用不起来：约束有 n 个，样本一多，通用二次规划求解器的内存和时间都撑不住。

唯一解在实际工程里意味着什么，值得说清楚。它意味着「同一份数据、同一组超参数，跑十次得到同一个模型」，意味着结果可以被审计、可以被别人复现、可以在出问题时倒推是数据变了还是参数变了。这在今天听起来是底线，在 1990 年代初不是：同一份数据训两个多层网络，你会得到两个权重不同的模型，而且没有任何数学理由说哪个更好。

### 2.2 对偶：解只依赖样本之间的内积

引入拉格朗日乘子 `α_i ≥ 0`，写出对偶：

```
max_α  Σ α_i − ½ ΣΣ α_i α_j y_i y_j (x_i·x_j)
s.t.   0 ≤ α_i ≤ C,   Σ α_i y_i = 0
```

KKT 条件给出一个很硬的结果：**只有 `α_i > 0` 的样本进入决策函数**，其余样本删掉不影响解。这些样本就是支撑向量。第 05 期那个「感知机看过的样本全部留在权重里」的问题，在这里被结构性地解决了——稀疏性来自约束的几何，不是靠事后剪枝。

更值得注意的是，对偶式里只剩 `x_i·x_j`，样本本身不再单独出现。1992 年 Boser、Guyon 和 Vapnik 在 COLT 上指出：既然只有内积，就可以把内积整体换成一个核函数 `K(x_i, x_j) = φ(x_i)·φ(x_j)`，等价于先把样本映射到高维空间、再在那里找最大间隔超平面——而映射 `φ` 从来不用显式算出来。

```
f(x) = Σ α_i y_i K(x_i, x) + b
```

这句话在 1990 年代是决定性的。1969 年那本《Perceptrons》卡住的是「线性分不开」（第 06 期），核函数提供了一个不经过隐藏层、也不经过反向传播的绕法：只换内积。

### 2.3 软间隔：允许犯错，代价由 C 定价

真实数据总有重叠，硬间隔会直接无解。1995 年 Cortes 和 Vapnik 加上松弛变量把约束放松：

```
min   ½‖w‖² + C Σ ξ_i
s.t.  y_i (w·φ(x_i) + b) ≥ 1 − ξ_i,   ξ_i ≥ 0
```

它等价于「L2 正则 + hinge loss」：`½‖w‖² + C Σ max(0, 1 − y_i·f(x_i))`。C 是这两项的汇率：C 大，宁可间隔窄也要把训练点分对；C 小，宁可错几个也要把路走宽。它不是准确率旋钮，是容量旋钮——这一点在第 5 段实测里能直接看到。

### 2.4 容量终于有了刻度

Vapnik–Chervonenkis 理论给出：以至少 `1 − δ` 的概率，

```
R(f) ≤ R_emp(f) + sqrt( ( h·(ln(2n/h) + 1) − ln(δ/4) ) / n )
```

其中 `h` 是假设空间的 VC 维。对间隔为 `γ`、数据落在半径 `R` 球内的线性分类器，`h ≤ min(R²/γ², d) + 1`。

这条不等式把两件原本混在一起的事分开了：**测试误差的上界 = 训练误差 + 容量项**。容量项可以通过加宽间隔来压——加宽间隔不是审美问题，是在缩小上界的第二项。这就是结构风险最小化，和「参数越多越好」是相反的思路：容量要能被度量、被控制。

### 2.5 本机复现

对偶问题用加速投影梯度（FISTA，每步投影到「盒约束 + 等式约束」的可行域上）求解，约 100 行；核函数三行一个。核心部分：

```python
def svm_fit(K, y, C=1.0, iters=2500):
    Q = (y[:, None] * y[None, :]) * K          # 对偶二次型，只用到核矩阵
    L = np.linalg.eigvalsh(Q).max()            # Lipschitz 常数
    a = np.zeros(len(y)); z = a.copy(); t = 1.0
    for _ in range(iters):
        a_new = project(z - (Q @ z - 1.0) / L, y, C)   # 投影：0<=a<=C, a'y=0
        t_new = 0.5 * (1.0 + np.sqrt(1.0 + 4.0 * t * t))
        z = a_new + ((t - 1.0) / t_new) * (a_new - a)
        a, t = a_new, t_new
    f_free = (a * y) @ K
    free = (a > 1e-7) & (a < C - 1e-7)
    return a, float(np.mean(y[free] - f_free[free]))     # b 由自由支撑向量定
```

第一组：24 个线性可分的二维点，同一套感知机规则，只换样本顺序。

```
顺序 0: 间隔 = 0.867, 法向角 = 28.3°
顺序 1: 间隔 = 0.834, 法向角 = 36.8°
顺序 2: 间隔 = 1.136, 法向角 = 25.8°
顺序 3: 间隔 = 1.342, 法向角 = 23.7°
顺序 4: 间隔 = 0.895, 法向角 = 46.6°
顺序 5: 间隔 = 0.867, 法向角 = 28.3°
-> 6 次都 100% 分开训练集；间隔最大 1.342、最小 0.834，相差 1.61 倍；法向角跨度 22.9°
```

同一批点，同一个凸问题，换 5 次顺序：

```
原顺序: ‖w‖ = 1.497054, b = +0.277059, 支撑向量 2 个, 间隔 = 1.336, KKT 残差 = 8.9e-06
顺序 0: ‖w‖ = 1.497054, b = +0.277059, 支撑向量 2 个, 间隔 = 1.336, KKT 残差 = 8.9e-06
顺序 2: ‖w‖ = 1.497073, b = +0.277097, 支撑向量 2 个, 间隔 = 1.336, KKT 残差 = 3.8e-06
-> 5 次解与原顺序解的最大绝对偏差 = 4.55e-05
-> SVM 间隔 1.336，对比感知机 6 个解里最宽的 1.342
```

偏差 4.55e-05 是求解器精度，不是解不唯一——KKT 残差 8.9e-06 说明已经收敛到同一个最优解。这里有个容易被忽略的细节：感知机 6 个解里最宽的那个（1.342）几乎等于 SVM 的间隔（1.336）。**最大值是碰出来的，不是规则保证的**；换个顺序就没了。

第三组，XOR 型四点：

```
linear: 决策值 = [ 0.45  -0.5    0.5   -0.475], 训练准确率 = 0.50, 支撑向量 4/4
poly2 : 决策值 = [-1.  1.  1. -1.], 训练准确率 = 1.00, 支撑向量 4/4
rbf   : 决策值 = [-1.  1.  1. -1.], 训练准确率 = 1.00, 支撑向量 4/4
```

二次核用的是 `K(u, v) = (1 + u·v)²`，整段代码里没有出现过 6 维特征向量的构造。核对它确实等于 6 维显式特征的内积：

```
k(u,v)        = 0.202500000000000
phi(u)·phi(v) = 0.202500000000000
|差|          = 4.72e-16   (输入 2 维 -> 特征 6 维)
24 个点的核矩阵与显式特征点积的最大偏差 = 7.11e-15
```

误差量级是浮点尾数误差。所谓「无限维特征空间」在计算上不是一个比喻，它是一个恒等式。

最后扫一遍 C。数据集加了两个越过对方边界的点，26 个样本：

| C | 训练准确率 | 间隔 | 支撑向量 | 其中 α=C（违约） |
|---|---|---|---|---|
| 0.01 | 0.96 | 6.337 | 26 | 26 |
| 0.10 | 0.96 | 2.446 | 12 | 9 |
| 1.00 | 0.96 | 1.462 | 5 | 3 |
| 100 | 1.00 | 0.190 | 3 | 1 |

C 从 0.01 抬到 100，间隔从 6.34 缩到 0.19，支撑向量从 26 个（全部贴在边界上）降到 3 个。C=100 时训练准确率到 1.00，但间隔只剩 0.19——决策边界被那个落在异类一侧的点拽得很窄。这就是「C 是容量旋钮」的实际表现：不是准确率换参数，是容量换准确率。

## 三、产物：三篇论文、一个数据集结果、一个求解器

1990 年代这条线留下的东西都很具体。

**1992 年，COLT**：Boser、Guyon、Vapnik 的《A training algorithm for optimal margin classifiers》，会议论文集第 144–152 页。核技巧第一次接进最大间隔分类器。更早的思想源头是 Aizerman 等人 1964 年的势函数法，但把它变成可用算法的是这一篇。

**1995 年，《Machine Learning》20(3): 273–297**：Cortes 和 Vapnik 的《Support-vector networks》。软间隔、完整算法、以及 USPS 手写数字库上的实验。这篇论文 1993 年 5 月 15 日收稿，1995 年 2 月 20 日接收——审了将近两年。

**USPS 的结果（9709 训练 / 2007 测试，10 个一对多分类器，误差取各类均值）**：

| 多项式次数 | 原始错误率 | 支撑向量（每类均值） | 特征空间维度 |
|---|---|---|---|
| 1（线性） | 12.0% | 200 | 256 |
| 2 | 4.7% | 127 | ~33,000 |
| 3 | 4.4% | 148 | ~10^6 |
| 6 | 4.2% | 185 | ~10^14 |

这张表里有两件事值得盯住。第一，**线性到二次，误差掉了 7.3 个点**；再往上加次数，收益迅速变平（4.7 → 4.2）。第二，六次多项式对应的特征空间在 10^14 维量级，支撑向量却只有 185 个——高维空间没有让模型变复杂，因为最大间隔把它约束住了。

**1995 年，Vapnik 的《The Nature of Statistical Learning Theory》**（Springer）：把 VC 维、结构风险最小化、SRM 归纳原则整理成一套完整理论。前面那条上界不等式就出自这条线。

**1998 年，Platt 的 SMO**：把大 QP 拆成每次只优化两个乘子的子问题，子问题有解析解，不需要通用 QP 求解器和巨大的核矩阵缓存。SVM 从「能发论文」变成「能装进一台工作站」，这是它在 2000 年代铺开的技术前提。

**1998 年，LeCun 等人的 MNIST 对比**：四次多项式 SVM 测试误差 1.1%，同一年 LeNet-5 是 0.95%。两条路线在这张表上只差 0.15 个百分点——那是卷积网络输得最少的一次，也是它在之后的十年里被核方法压住的起点。

**1998 年之后，文本分类**：Joachims 的 SVM-light 让 SVM 在 TF-IDF 稀疏特征上跑起来。文本的维度本来就高（词表 10^5 量级）、样本稀疏，此时线性核往往就够了，核函数的复杂度反而不是必需品——这也解释了后来大规模场景为什么回到线性模型。

## 四、代价，以及它留下的语言

代价是算力。核矩阵是 n×n：n=10^5 时，float64 下约 80 GB，还没算 O(n³) 的通用求解。这个数字决定了 SVM 在 2000 年代中后期让位给线性模型 + 随机梯度（LIBLINEAR，2008），再往后让位给深度网络。核近似（Nyström、随机特征）和各向同性核在现代模型里仍然出现，但它们是工具，不是主线。

还有一个代价是隐性的：核函数选错了，间隔再宽也没用。多项式核的次数、RBF 核的 `γ`，本质上和隐藏单元的数量一样，都是容量参数，都要靠交叉验证挑。1990 年代这套理论把容量变得可度量，但没有把容量变得自动——SVM 在这一点上并没有比神经网络轻松，只是它的每一次失败都更容易被解释成「核选得不对」，而不是「运气不好」。

留下的语言比算法本身更耐用：**把学习写成一个带容量约束的优化问题，解的存在性、唯一性、稀疏性都由问题结构决定，而不是由训练技巧决定**。今天读一个损失函数，先问它是不是凸的、正则项在约束什么容量、解的稀疏性从哪来——这套提问方式来自 1990 年代，不是来自 2012 年。
