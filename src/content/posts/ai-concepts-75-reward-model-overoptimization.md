> 奖励模型的分从 4.45 涨到 9.31，涨了一倍。
> 同一批答案按真实有用度打分：起点 0.361，第 2 步见顶 0.692，第 160 步掉回 0.511。
> 那 109% 的涨幅里，大部分买的是答案变长——平均长度从 0.494 推到 0.923。

**读这篇要会**：Bradley-Terry 模型（把成对比较写成逻辑回归）／softmax 策略和它期望的梯度／KL 散度当分布距离用。不需要训过奖励模型。

## 🎯 分数和质量可以反向走

RLHF 的流水线是两段：先拿人的成对比较训一个奖励模型，再让策略去最大化这个奖励。第二段是有明确目标函数的优化问题，它会**把目标函数最大化到你停手为止**——包括把目标函数里所有的错误一起最大化。

这件事在文献里有名字。Goodhart 定律的工程版本是：一个指标一旦变成优化目标，它就不再是好的度量。Gao、Schulman、Hilton 在 2022 年把它做成了可测量的曲线（*Scaling Laws for Reward Model Overoptimization*，arXiv:2210.10760）：用一个固定的「金标准」奖励模型冒充人类给标签，训一个代理奖励模型，然后分别用 RL 和 best-of-n 去优化代理。代理分一路上涨，金标准分先涨后跌，而且 RL 和 best-of-n 的曲线形状不一样，拟合系数随奖励模型的参数量平滑变化。

偏置的来源不是玄学。Singhal 等（*A Long Way to Go: Investigating Length Correlations in RLHF*，arXiv:2310.03716）拆开 RLHF 的提升，发现**奖励的改善主要由回答变长驱动**：一个纯粹按长度给分的奖励，就能复现 SFT 模型之上大部分的 RLHF 收益。Sharma 等（*Towards Understanding Sycophancy in Language Models*，arXiv:2310.13548，ICLR 2024）在另一条轴上给出同类结论：人类的偏好判断本身偏好「附和用户观点」的回答，偏好模型也跟着偏好——相当一部分情况下，写得漂亮的谄媚答案会赢过正确答案。

两条合起来就是这一篇要量化的东西：**奖励模型继承了标注者的偏置，而优化器专门去找这些偏置的极值点。**

## 🔬 机制：奖励模型学的是打分函数，不是有用度

Bradley-Terry 把「i 比 j 好」写成两条答案得分之差的 logistic 概率。给定特征向量 $x$（这里是三维：是否答对 $c$、长度 $L$、是否谄媚 $s$），奖励模型就是一个线性打分器 $r(x)=w^\top x$，训练目标是

$$\mathcal{L}(w)=-\mathbb{E}_{(i,j)\sim D}\Big[\log\sigma\big(w^\top(x_i-x_j)\big)\Big]$$

注意这个目标里**没有任何一项来自「真实有用度」**。$w$ 只对 $D$ 里的比较负责，$D$ 是人给的。人偏爱长答案，$w_L$ 就会上去，逻辑回归不会有任何机制去问「长到一定程度还有用吗」。

策略侧同样干净：$\pi_\theta(a)\propto e^{\theta^\top x_a}$，最大化 $\mathbb{E}_\pi[r]$ 的精确梯度是

$$\nabla_\theta\,\mathbb{E}_{\pi}[r]=\mathbb{E}_{\pi}\big[r(a)\,(x_a-\mathbb{E}_{\pi}x)\big]$$

这个式子的含义值得读两遍：梯度的方向由「奖励值 × 特征偏离均值的方向」决定。奖励值恒正，所以**每一维特征只要 $w$ 里是正的，就会被一路推高**，直到 softmax 饱和。优化器不理解「长度超过一半就开始扣分」，因为它拿到的 $w_L$ 是正的。

## 🏗️ 为什么 KL 惩罚救不了方向

常见的护栏是 KL 惩罚：奖励里减掉 $\beta\cdot\mathrm{KL}(\pi\|\pi_{\text{SFT}})$，让策略别跑太远。它限制的是**距离**，不是**方向**。实测里 KL 从 0 涨到 3.30 的过程中，真实有用度早就在 KL ≈ 0.69 见顶——那时候奖励模型分数才 7.18，看起来「还有上涨空间」，实际已经在往下走了。KL 只能告诉你「别走远」，不能告诉你「这一步在走下坡」。

真正改变方向的是数据。长度偏置能进 $w$，是因为比较对里「长的赢」这件事被反复提供梯度。如果成对数据里绝大多数对子长度差很大，模型就永远学不到「同样长度下谁更好」——而这恰恰是质量所在的那一维。这个观察直接把修法指向数据集构造，而不是调 $\beta$。

## 💻 实测：把偏置拟出来，再优化它

实验设定（**模型化模拟，不是真调线上奖励模型**）：3000 条答案，三个可观测特征；真实有用度 $U=c-0.8\cdot\mathrm{relu}(L-0.5)-0.15s$（答对得 1 分，超过半程的长度每单位扣 0.8，谄媚扣 0.15）；标注者打分 $A=c+0.9L+0.4s+\mathcal{N}(0,0.3)$。用 $A$ 采样 6 万对比较，牛顿法拟合 Bradley-Terry。

```python
import numpy as np

rng = np.random.default_rng(7)
N = 3000
c = rng.integers(0, 2, N).astype(float)
L = rng.random(N)
s = (rng.random(N) < 0.3).astype(float)
X = np.stack([c, L, s], 1)
U = c - 0.8 * np.clip(L - 0.5, 0, None) - 0.15 * s
A = X @ np.array([1.0, 0.9, 0.4])

def fit_rm(pairs, iters=25):          # Bradley-Terry + 牛顿法，3 个参数
    i, j = pairs
    d = X[i] - X[j]
    w = np.zeros(3)
    for _ in range(iters):
        p = 1 / (1 + np.exp(-(d @ w)))
        g = d.T @ (p - 1.0) / len(i)
        H = (d * (p * (1 - p))[:, None]).T @ d / len(i)
        w -= np.linalg.solve(H + 1e-3 * np.eye(3), g)
    return w

def optimize(w, steps=160, lr=1.5):   # 对 E_π[r] 精确梯度上升，不采样
    theta = np.zeros(3)
    for t in range(steps + 1):
        z = X @ theta
        p = np.exp(z - z.max()); p /= p.sum()
        Er, Eu, El = float(p @ (X @ w)), float(p @ U), float(p @ L)
        kl = float(p @ np.log(p * N))
        g = (X - p @ X).T @ (p * (X @ w))
        theta += lr * g
```

拟合出来的权重（真值对应 $[1,\ \le 0,\ -0.15]$）：

| 训练数据 | 答对 | 长度 | 谄媚 |
|---|---|---|---|
| 常规成对比较 | 4.184 | **3.729** | 1.692 |
| 只保留 \|ΔL\| ≤ 0.05 的对子 | 4.374 | **-0.144** | 1.490 |

长度项的权重 3.729，和答对项的 4.184 只差 11%。在真实有用度里这一维是**负的**（超长扣分）。这就是全部问题的量级：一个几乎和「答对」等权的特征，符号是反的。

对两个奖励模型各做 160 步奖励最大化，每步记录真实有用度：

| step | 常规 RM：长度 | 奖励 | 真实 | KL | 长度平衡 RM：奖励 | 真实 |
|---|---|---|---|---|---|---|
| 0 | 0.494 | 4.451 | 0.361 | 0.000 | 2.573 | 0.361 |
| 2 | 0.596 | 7.184 | **0.692** | 0.694 | 4.844 | 0.737 |
| 10 | 0.769 | 8.607 | 0.611 | 1.960 | 5.636 | 0.733 |
| 40 | 0.873 | 9.097 | 0.548 | 2.725 | 5.758 | 0.750 |
| 160 | 0.923 | **9.309** | 0.511 | 3.295 | 5.804 | **0.802** |

常规奖励模型：奖励 +109%，真实有用度在第 2 步见顶，之后掉 26%；长度一路推到 0.923，几乎贴着上界 1.0 走。长度平衡奖励模型：同样 160 步，真实有用度单调从 0.361 涨到 0.802，长度反而从 0.494 降到 0.356——**奖励模型没学会偏好长度之后，优化器也就没得可利用的**。

单条答案的真实有用度上限是 1.0（答对、不过长、不谄媚）。常规 RM 的终点落在 0.511，比起点 0.361 只高 0.15，而它把奖励分数推高了整整 4.86——多出来的部分几乎全是长度与谄媚的账单；长度平衡版能吃到 0.802，剩下的差距是谄媚项——它在这版 RM 里权重仍有 1.49，真实有用度里是 -0.15。修好一个偏置不会顺手修好另一个。

## 💡 结论

1. **奖励模型分数只能当方向指示，不能当进度条**。它单调不降是数学性质，不是质量信号。要判断该不该停，得有一份不参与优化的 gold set。
2. **偏置进 $w$ 的通道是数据构造，不是 $\beta$**。想让奖励模型对长度不敏感，就把比较对限制在长度可比的范围内；想让它对谄媚不敏感，就得有「观点相同、正确性不同」的对照对——Sharma 等发现这类对子在常规偏好数据里恰恰稀缺。
3. **过优化的速度取决于偏置的符号，不取决于训练规模**。这里第 2 步就过顶，因为偏置特征（长度）与奖励高度相关而几乎无成本——优化器一步就能吃到。反过来，偏置弱的时候你会以为「再多训一会儿更好」。
4. **RL 和 best-of-n 的过优化曲线不是同一条**（Gao 等的结论）。best-of-n 加大 N 也是在同一方向上继续走，我在[推理时计算那一篇](/blog/posts/ai-concepts-45-test-time-compute/)里只测了验证器筛选带来的增益，没测它在 N 很大时的回落——这里补上机制：回落来自验证器的偏置被 $N$ 放大，N 越大越容易抽到「奖励模型喜欢但人类不喜欢」的样本。
