> 1997 年 5 月 11 日，一台机器在国际象棋上赢了世界冠军。六个月后，一篇 44 页的论文讲清了另一件事：梯度凭什么能穿过一千步而不归零。前者举国皆知，后者当时只有几百个人读。

**读这篇要会**：矩阵乘法的链式法则 / 循环神经网络里 h_t = tanh(W h_{t-1} + U x_t) 这种递推形式 / 雅可比矩阵是什么、为什么它的连乘长度决定梯度存活 / BPTT 的大意。

---

## 一、卡点：1997 年，两条路各自撞上了自己的墙

1990 年代中期的 AI 有两条主线，它们在 1997 年同一个月里分别给出了自己那一侧的最优解和失败证明。

一条是搜索加手工知识。国际象棋的分支因子约 35，一步棋之后三十五个选择，十步之后是 35 的十次方量级。没有哪台机器能把整棵树算完，所以「棋力」= 看得更深 + 评价得更准。看得更深靠专用硬件，评价得更准靠人。1997 年的 Deep Blue 是这条路线的极限形态：它把一半的棋力固化在硅片里，另一半固化在几位特级大师的脑子上。它赢了棋王，但它的每一分棋力都不能搬到别的任务上去——换一个游戏，480 块芯片、八千条评估特征、几十万行手写搜索代码全部作废。

另一条是连接主义。1986 年反向传播解决了信用分配，多层网络第一次能训（第 08 期）。但网络被要求做「序列到序列」的事情时，一个新的死结浮出来了：**梯度要穿过时间**。序列模型的对齐依赖是：第 1 步读到的信息，第 50 步才用得上。反向传播要把第 50 步的误差送回第 1 步，途中经过 49 次同一个雅可比矩阵的连乘。

1994 年，Bengio、Simard 和 Frasconi 在 IEEE Transactions on Neural Networks（5(2):157–166）上把这件事故意做成了定理形式的经验陈述：梯度随时间反向传播时，要么指数爆炸，要么指数消失，中间没有稳定区。这不是调参问题，是结构问题——乘积的模长由每一步的局部导数决定，而 tanh 的导数上界是 1，再乘上一个本征值小于 1 的权重矩阵，衰减是必然的。

于是 1997 年摆在桌面上的问题是：**能不能设计一个循环结构，让梯度在时间维度上不被反复打折？** 注意问法——不是「让梯度更大」，而是「让它不被乘」。这两个问法的差别，就是这篇文章的全部内容。

## 二、机制 A：Deep Blue 赢的是搜索，不是学习

先把 Deep Blue 的结构讲清楚，因为它常被误读成「AI 变聪明了」。它不是。

1997 年的系统是 IBM RS/6000 SP 上的 30 个节点，每个节点挂 16 块专用棋芯片，共 480 块。每块芯片 1.5 百万晶体管、0.6 微米工艺、功耗 1 瓦、面积 1.4×1.4 厘米，内部集成走法生成器、评估函数、alpha-beta 搜索控制器——一块芯片单独拿出来就是一台完整的国际象棋机，单芯片速度 2 到 2.5 百万局面/秒。整机持续速度约 2 亿局面/秒，峰值接近 10 亿。

搜索是两层并行的。主节点先在软件里算根节点往下的 4 层，此时局面数涨了约一千倍，分发给 30 个节点；软件再算 4 层，局面数再涨一千倍，交给芯片算最后 4 层加固静止搜索。所以基础深度是 12 层，但在「强制着法」的线路上会做选择性延伸，实战中延伸后能到 40 层左右。

有一个细节值得单独说，因为它揭示了这套系统的真实分工：**软件只处理了不到 1% 的局面，却控制着大约三分之二的搜索深度**。胜负手在选择性延伸——决定「哪条线值得往下钻」的那部分逻辑，是人写的。芯片提供的是广度，不是判断力。

判断力来自评估函数，由顶尖棋手参与调参，IBM 在备战期同时雇了四五位特级大师。这就是为什么 1996 年 2 月费城那场 4–2 的失利之后，Deep Blue 变强的路径是「换更快的芯片 + 加更多特级大师」——而不是「让它多下几百万盘棋自己总结」。整场 1997 年的比赛里，Deep Blue 的权重没有变过一个比特。它没有学习组件。

这里必须交代一件有争议的事。1997 年第一局，Deep Blue 在败势下第 44 回合走出一步看似毫无道理的着法，卡斯帕罗夫赛后反复推演，据他自述无法用「程序算得浅」解释，只能认为对手看到了极深的东西。这个判断影响了他后面几局的心态。十五年后，开发者 Murray Campbell 在 Nate Silver 的《The Signal and the Noise》（2012）中给出另一种解释：程序那一手是因为缺陷没能正常选出着法，退回到了「随便走一步合法棋」的兜底逻辑。这条归因来自单一当事人的事后回忆，卡斯帕罗夫本人并不接受，也无法从比赛记录独立验证——它被广泛引用，但它不是定论。可以确定的是当时的比分（3.5–2.5）和那台机器的构成，不能确定的是那一手棋到底意味着什么。

比赛结束不到一个月，IBM 拆解了 Deep Blue，项目终止。这条路线留下的产物是一套专用加速器设计思路和一批论文，没有留下可复用的学习算法。二十年后，同一个棋类被另一条路线解决：AlphaZero 从零开始自我对弈，评估函数由网络自己学出来，不再需要特级大师调参。搜索没有死，但「靠人把知识写进评估函数」这一半死透了。

## 三、机制 B：把梯度乘 1

### 3.1 先把「衰减」量出来

标准循环网络是 `h_t = tanh(W h_{t-1})`。误差从第 T 步回传到第 0 步，要连乘 T 个雅可比矩阵：

```
∂h_t/∂h_{t-1} = diag(1 - h_t²) · W
```

连乘的范数上界是各步范数的乘积。如果每步的典型范数是 0.9，一百步之后是 0.9¹⁰⁰ ≈ 2.7e-05；如果每步是 1.35，一百步之后是 1.35¹⁰⁰ 量级，梯度直接数值溢出。中间那个「既不变大也不变小」的区间，只在一个孤立的参数点上存在，随机初始化几乎不可能停在那里。

这是本机实测的读数（32 维隐藏层，100 组随机 W，取中位数）：

```
   T      rho=0.9     rho=1.35        常数误差传送带
   1    1.457e+00    2.040e+00            1.0
   5    9.648e-01    3.665e+00            1.0
  10    5.303e-01    5.400e+00            1.0
  20    1.612e-01    5.750e+00            1.0
  50    6.913e-03    6.956e+00            1.0
 100    3.607e-05    6.534e+00            1.0
```

左边两列是同一种结构的两种死法：谱半径略小于 1 时误差信号在 100 步后只剩初始的十万分之四；略大于 1 时它放大到 6.5 倍并继续随步数增长——训练时表现为权重振荡。第三列是 LSTM 的答案：**恒等于 1**。不是「大约 1」，是结构上精确的 1，因为它根本没有乘任何东西。

### 3.2 传送带：c_t = c_{t-1} + i_t · g_t

LSTM 的核心单元叫常数误差传送带（constant error carousel）。它把记忆从「隐状态 h」挪到一个单独的状态 c 上，并且让 c 的更新是**加法**而不是乘法：

```
c_t = c_{t-1} + i_t ⊙ g_t
h_t = o_t ⊙ tanh(c_t)
i_t = σ(W_i x_t + U_i h_{t-1} + b_i)     输入门
o_t = σ(W_o x_t + U_o h_{t-1} + b_o)     输出门
g_t = tanh(W_g x_t + U_g h_{t-1} + b_g)  候选值
```

对 c 求导，`∂c_t/∂c_{t-1} = 1`。误差回传时，dc 每经过一步只是被**加**上来自输出端的那一份，不会被乘上一个小于 1 的因子。上面那张表第三列的那个 1.0，就是这一行式子的直接结果。

门的作用是控制「谁可以进、谁可以出」，而门的参数本身是用梯度学的。这一点比结构本身更关键：网络不只学会了记住什么，还学会了自己决定什么时候该记、什么时候该放。i_t 关掉，新的输入进不来；o_t 关掉，记忆不外泄——对下游表现为「这段时间我什么都没想」。

1997 年那篇论文的实验目标写得很直接：桥接超过 1000 个离散时间步的最小延迟。1000 步这个量级，在 1994 年的结论下是彻底的禁区——按每步 0.9 的衰减算，信号会小到 1e-46。

### 3.3 一个必须说清的历史细节：原版没有遗忘门

`c_t = c_{t-1} + i_t g_t` 里 c 只会增加、不会减少。当输入门长期开着、候选值又总是正数时，c 会一路单调增长，最后撑到 tanh 饱和，单元就失去分辨率。这个问题的补丁是遗忘门 `c_t = f_t ⊙ c_{t-1} + i_t ⊙ g_t`，由 Gers、Schmidhuber 和 Cummins 在 2000 年补上（Neural Computation 12(10):2451–2471，标题就叫 Learning to Forget）。今天所有框架里的 `nn.LSTM` 默认带遗忘门，所以「LSTM 有三个门」是 2000 年之后的说法，不是 1997 年的。

### 3.4 跑起来：延迟回忆

机制只有真跑一遍才知道是不是这么回事。任务是标准的延迟回忆：序列长 T，第 1 步给一个随机比特，中间全是 0，要求在第 T 步输出那个比特。这个任务没有任何捷径——模型要么把信息存在状态里跨过 T 步，要么只能瞎猜。

下面是把单元写成 numpy 的那部分，58 行，手工 BPTT，梯度用有限差分核对过（最大相对误差 5e-09 量级）：

```python
def forward(self, X):
    n, T = X.shape[0], X.shape[1]
    c = np.zeros((n, self.H)); h = np.zeros((n, self.H)); cache = []
    for t in range(T):
        z = X[:, t] @ self.p["Wx"].reshape(4*H, 1).T \
          + h @ self.p["Wh"].reshape(4*H, H).T + self.p["b"].reshape(-1)
        i, g = sigmoid(z[:, :H]), np.tanh(z[:, H:2*H])
        o = sigmoid(z[:, 3*H:])
        c_new = c + i * g                 # 加法：∂c_t/∂c_{t-1} = 1
        h_new = o * np.tanh(c_new)
        cache.append((h.copy(), c.copy(), i, g, o, c_new))
        h, c = h_new, c_new
    return h @ self.p["Wy"].T, cache
```

反向那一侧的关键只有一行注释：

```python
dc = dc + dh * o * (1 - tc**2)   # 输出端贡献直接相加，不乘衰减
...
dh = dz @ p["Wh"].reshape(4*H, H)
# 无遗忘门：dc 原样传回上一步
```

T=50、隐藏层 24 维、训练 800 条、测试 400 条、Adam、150 轮，真实输出：

```
[vanilla RNN] 梯度核对最大相对误差 1.81e-09
  epoch   1  train loss 0.6935  test acc 0.495
  epoch  50  train loss 0.6923  test acc 0.495
  epoch 150  train loss 0.6931  test acc 0.495

[LSTM(1997)] 梯度核对最大相对误差 4.64e-09
  epoch   1  train loss 0.0068  test acc 1.000
  epoch  50  train loss 0.0001  test acc 1.000
  epoch 150  train loss 0.0000  test acc 1.000
```

0.6931 是 ln2，二分类对半猜的理论损失。原始 RNN 在这种长度下不是「学得慢」，是**完全没有信号**：150 轮里损失在第三位小数上抖动，测试准确率始终停在 0.495。LSTM 第一轮就到了 1.000——因为输入门偏置初始化成 1（原论文的建议：让单元一开始就处于「记住」状态），加上传送带本身不衰减，梯度一步就能摸到该改哪个参数。

同一份代码还给出了一个反直觉的读数：把这个任务缩短到 T=12，原始 RNN 也能做到 1.000。**这条路线的失效不是渐进的，是有阈值的**——短时滞上两者无差别，越过某条线之后一个断崖式失效、另一个毫无变化。工程上这意味着，用 RNN 做了一个能跑的原型，并不能推出它在长序列上还能跑。

## 四、产物

**1997 年 5 月 3–11 日，纽约 Equitable Center**：Deep Blue 与卡斯帕罗夫六局，比分 3.5–2.5，机器赢。总奖金 110 万美元，IBM 拿 70 万。它是第一个在标准比赛时限下击败在位世界冠军的计算机系统。同年 IBM 拆解机器，不再参赛，也没有公开完整的对局日志与评估函数源代码。

**1997 年 11 月，Neural Computation 9(8):1735–1780**：Hochreiter 与 Schmidhuber 的《Long Short-Term Memory》，44 页。摘要里给出的数字是「桥接超过 1000 个离散时间步的最小延迟」，并且明确对比了 RTRL、BPTT、Recurrent Cascade-Correlation、Elman 网络和 Neural Sequence Chunking 五种方法，报告 LSTM 的成功运行次数更多、学习更快、解出了此前没有循环网络算法解出过的长时滞任务。复杂度声明是每步每权重 O(1)。

两条线的后续走向完全相反。搜索那条线靠硬件和手工知识已经到顶，1997 年之后它的每一次进步都来自换算法：2005 年蒙特卡洛树搜索、2017 年 AlphaZero 的自我对弈。LSTM 那条线在随后十几年里被反复加固和替换：2000 年加遗忘门、2000 年加窥视孔连接、2005 年 Graves 与 Schmidhuber 把双向 LSTM 用于音素分类（IJCAI 2005）、2009 年 Graves 等人的连接主义手写识别系统（IEEE TPAMI 31(5):855–868）在 ICDAR 2009 的三项手写识别竞赛中全部第一、2014 年 Sutskever 等人的 seq2seq 用堆叠 LSTM 做机器翻译（NIPS 2014）、2016 年 Google 的 GNMT 把它推上生产系统。

还有一条更隐蔽的产物：**门控这个想法本身**。1997 年论文里真正被继承下来的不是 LSTM 这个具体结构，而是「用乘性门控去调制一条不衰减的信息通路」这个设计模式。GRU 是它的简化版，Transformer 里的门控前馈和后来的状态空间模型都还在用同一个句式。2023 年之后大量所谓「线性注意力」「选择性状态空间」的改进，本质上还是在回答同一个问题：怎么让信息在长序列上不被反复打折，同时又能被训练信号关掉。

## 五、下一篇：深不是问题，深度是

1997 年解决的是**时间**维度的梯度衰减：一条恒为 1 的传送带让误差能穿过一千步。

但同一时期还有另一个维度没被解决：**层**。2006 年之前，超过三四层的网络在实践中训不动，原因和 1994 年那份分析高度相似——只是连乘的方向从时间轴换成了层轴，而且这次连乘里混进了非线性的饱和区和糟糕的初始化。2006 年，Hinton 与 Salakhutdinov 用逐层无监督预训练绕开了它，Bengio 等人同年给出另一种解释。两年后，事情被一个更朴素的改动解决：换初始化。
