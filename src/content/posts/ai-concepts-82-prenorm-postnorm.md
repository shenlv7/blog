> 同一份 Glorot 初始化、同样 24 层、同样 d=256、同一个 loss：
> **Pre-LN 的残差流从 15.92 长到 49.13（3.09 倍），逐层 ‖dW‖ 却只差 1.36 倍**；
> **Post-LN 的流被每层 LN 钉死在 16.000，‖dW‖ 却从首层 47.1 爬到末层 144.3（3.07 倍）**。
> 一个把不稳定的东西从梯度搬到了流的尺度上，一个把流管死了、把梯度放出笼子。
> 而那个 3.09 倍的增长，用**一个常数 c=9.678** 就能复现到 1.79% 以内。

读这篇要会：LayerNorm 的输入输出（减均值、除标准差、再仿射）/ 残差连接的梯度直通 / 反向传播的链式法则与雅可比矩阵。

## 🎯 两种写法，只差一个位置

Transformer 里那个 LN 放在残差加法前面还是后面，从代码看就是一个括号的位置：

$$
\text{Pre-LN:}\quad x_{l+1} = x_l + F_l\big(\mathrm{LN}(x_l)\big)
\qquad
\text{Post-LN:}\quad x_{l+1} = \mathrm{LN}\big(x_l + F_l(x_l)\big)
$$

$F_l$ 是注意力或 FFN 那一块。区别只有一件事：**$x_l$ 本身被不被归一化**。

Pre-LN 把 LN 放在写入之前——它只保证「送进 $F_l$ 的东西尺度正常」，流 $x_l$ 自己没人管。Post-LN 把 LN 放在写入之后——流每一层都被压回 $\sigma=1$ 的状态，于是 $x_l$ 的尺度是受控的，代价是每一层多了一次雅可比连乘。

LN 的雅可比是这三个矩阵之一：

$$
\frac{\partial\,\mathrm{LN}(x)}{\partial x}
= \frac{1}{\sigma}\left(I - \frac{1}{d}\mathbf{1}\mathbf{1}^{\top} - \frac{1}{d}\hat{y}\hat{y}^{\top}\right),
\qquad \hat{y}=\frac{x-\mu}{\sigma}
$$

$I$ 那一项是恒等（梯度原样传回去），后面两项分别扣掉均值方向和当前样本方向。**注意系数 $\frac{1}{\sigma}$**——它是后面所有数字的来源：$\sigma$ 一变，梯度量级就跟着变。

## 🔬 初始化时刻能测出什么

这两种写法的差别，**不用训练就能量出来**，因为它是结构性的：梯度量级、流的尺度、单块删除的后果，都由前向的雅可比决定。训练只会在这些量上叠加优化器动力学，把问题搅浑。

设置：24 层，$d=256$，FFN 隐藏维 512，GELU，Glorot 均匀初始化，batch 64，loss 取 $\frac{1}{B}\sum_b \text{out}_b \cdot r$（$r$ 是固定随机向量，只为让梯度有方向）。三个测量：

1. **流范数**：每层输出按行的 L2 范数均值，看 $x_l$ 随深度怎么走；
2. **逐层梯度**：每层 $\|dW_1\|_F^2+\|dW_2\|_F^2$ 的平方根，看反向传播到此还剩多少；
3. **单层删除敏感度**：把第 $l$ 层替换成纯恒等路径，看最终输出相对变化多少。

反传是手写的（numpy，无框架），每一步都和有限差分对照过：Pre-LN 最大相对误差 $1.4\times10^{-8}$，Post-LN $3.7\times10^{-7}$。自检不通过的数字不要往文章里写。

实测（节选，全部 24 层和深度扫描都在脚本输出里）：

| 指标 | Pre-LN | Post-LN |
|---|---|---|
| 流范数（L1 → L24） | 15.92 → **49.13**（3.09×） | 15.92 → **16.000**（1.00×） |
| 每层范数增量份额 | 17.14% → **1.55%** | 0.49% 后恒为 0.00% |
| ‖dW‖ 首层 → 末层 | 169.2 → 132.4（0.79×） | 47.1 → 144.3（**3.07×**） |
| 逐层梯度极差（最大/最小） | 1.36× | **3.13×** |
| 单层删除 Δ（L1 → L24） | 55.2% → **18.9%** | 61.1% → **50.7%**（全程 50–62%） |

同样一份权重分布，一边的流在 24 层里胖了三倍，一边的流精确地不动；一边的梯度逐层几乎平行，一边的梯度沿深度系统性地爬了 3 倍。**这两件事是同一个括号位置的两个后果，不可能只要其中一个。**

## 🏗️ 流为什么按 √L 长

Pre-LN 里每层做的事是「往流里加一个增量」。$F_l(\mathrm{LN}(x_l))$ 的输入是归一化过的，尺度固定——LN 输出每行的范数恰好是 $\sqrt{d}=16.000$，而 Glorot 初始化的 MLP 对这个固定尺度输入给出的输出范数是个常数。实测这个常数是 $c=9.678$。

如果增量彼此近似正交，那么

$$
\|x_L\|^2 \approx \|x_0\|^2 + L\,c^2
\quad\Longrightarrow\quad
\|x_L\| \propto \sqrt{L}
$$

把 $c=9.678$ 代进去，对 $l=1..24$ 全部预测：

- $l=1$：预测 18.63，实测 18.65
- $l=6$：预测 28.56，实测 28.78
- $l=12$：预测 37.11，实测 36.92
- $l=24$：预测 50.01，实测 49.13

**最大相对误差 1.79%，24 层全中。** 也就是说这个 24 层网络的流范数，除了一个常数没有别的自由度——每层的贡献在绝对量上完全一样。

而人在乎的是相对量。每层范数增量占当前流的比例，实测从 17.14% 单调掉到 1.55%，**24 层掉了 11 倍**。用上面的式子推一下就知道为什么：份额 $\approx c^2/(2\|x_l\|^2) \propto 1/l$。深层不是「学得少」，是它写进去的那一笔，在越来越粗的流里只占个零头。

这件事有两种读法，都是真的：

- **好消息**：梯度沿残差路径直通（那个 $I$ 的雅可比），所以逐层梯度量级守恒（1.36 倍极差），24 层不需要 warmup 也不会梯度消失；
- **坏消息**：流的尺度没人管，$\|x_{24}\|/\|x_0\| = 3.09$，最后接 logits 的那层线性映射看到的输入尺度随深度漂。所以**所有 Pre-LN 模型都必须有一个 final norm**——不是可选的美化，是否则输出 logits 的尺度随深度变化，温度、初始化、学习率全部跟着错位。LLaMA 系列用 pre-RMSNorm 也是同一个逻辑：RMSNorm 只是把 LN 的雅可比里 $-\frac{1}{d}\mathbf{1}\mathbf{1}^{\top}$ 那一项去掉（不减均值），流照样会长，final norm 照样必须有。

Post-LN 那边正好相反。每层末尾的 LN 把 $\sigma$ 压回 1，流精确停在 16.000（就是 $\sqrt{d}$）——**删除敏感度的平坦（50–62%）就是这件事的直接证据**：删掉任何一层，下一层的 LN 立刻把流的统计复原，损失只是那一层自己的函数；Pre-LN 里删掉早层，后面所有层看到的流尺度都变了，破坏力单调从 55.2% 降到 18.9%。

代价在梯度上。Post-LN 每一层都多乘一个 $\frac{1}{\sigma}$ 的雅可比，24 层连乘下来，首层拿到的 $\|dW\|$ 是 47.1，末层 144.3。**首末比 0.326，逐层极差 3.13 倍，而且首层的绝对值只有 Pre-LN 的 1/3.6（47.1 对 169.2）。** 同样一个学习率，浅层走得比深层慢一个量级——这是 warmup 讨论真正的物理起点：不是「梯度消失」（3 倍不叫消失），是**梯度尺度沿深度有系统性倾斜，且整体偏小**。

顺带一个反直觉的结果：把深度从 6 层扫到 48 层，这个倾斜不随深度恶化。

| 深度 | Pre-LN 首/末层梯度比 | Post-LN 首/末层梯度比 |
|---|---|---|
| 6 | 0.99 | 0.59 |
| 12 | 1.14 | 0.37 |
| 24 | 1.43 | 0.31 |
| 48 | 1.51 | 0.33 |

Post-LN 到 24 层就稳定在 0.31–0.33，48 层没有更差；Pre-LN 反而随深度略微上升（0.99 → 1.51）。**「深了才出事」在初始化时刻的量级上是假的**，出问题的是训练动力学（LN 输出端对 $\sigma$ 的敏感性随激活分布变化），那要靠训练曲线看，不在本文的测量范围里。

## 💻 40 行量完一个括号

核心只有 LN 的前向与反向，加两个分支的梯度。Post-LN 的输入梯度有两条路径——残差那条和穿过 MLP 那条（$\partial u/\partial x = I + \partial F/\partial x$），只写 `dout = du` 会让 3 层网络的第 1 层 $dW$ 和有限差分差 7.79 倍；补上 `da @ W1.T` 之后降到 $3.7\times10^{-7}$。所以脚本开头永远先跑一次有限差分自检。

```python
import numpy as np
rng = np.random.default_rng(20261114)
D, HID, B, EPS = 256, 512, 64, 1e-5

def gelu(x):
    c = np.sqrt(2 / np.pi)
    return 0.5 * x * (1 + np.tanh(c * (x + 0.044715 * x ** 3)))

def dgelu(x):
    c = np.sqrt(2 / np.pi); t = np.tanh(c * (x + 0.044715 * x ** 3))
    return 0.5 * (1 + t) + 0.5 * x * (1 - t ** 2) * c * (1 + 3 * 0.044715 * x ** 2)

def ln_fwd(x, g, b):
    mu, var = x.mean(-1, keepdims=True), x.var(-1, keepdims=True)
    inv = 1.0 / np.sqrt(var + EPS)
    yhat = (x - mu) * inv
    return yhat * g + b, yhat, inv

def ln_bwd(dy, yhat, inv, g):
    dyh = dy * g
    dx = inv * (dyh - dyh.mean(-1, keepdims=True)
                - yhat * (dyh * yhat).mean(-1, keepdims=True))
    return dx, (dy * yhat).sum(0), dy.sum(0)

def init_block():
    lim = np.sqrt(6.0 / (D + HID))
    return dict(W1=rng.uniform(-lim, lim, (D, HID)), b1=np.zeros(HID),
                W2=rng.uniform(-lim, lim, (HID, D)), b2=np.zeros(D),
                g=np.ones(D), be=np.zeros(D))

def forward(net, x, kind):
    norms, caches = [np.linalg.norm(x, axis=1).mean()], []
    for p in net:
        if kind == 'pre':                       # x_{l+1} = x + F(LN(x))
            y, yhat, inv = ln_fwd(x, p['g'], p['be'])
            a = y @ p['W1'] + p['b1']; h = gelu(a); z = h @ p['W2'] + p['b2']
            caches.append(('pre', y, a, h, yhat, inv, p)); x = x + z
        else:                                   # x_{l+1} = LN(x + F(x))
            a = x @ p['W1'] + p['b1']; h = gelu(a); z = h @ p['W2'] + p['b2']
            u = x + z
            x, yhat, inv = ln_fwd(u, p['g'], p['be'])
            caches.append(('post', x, a, h, yhat, inv, p))
        norms.append(np.linalg.norm(x, axis=1).mean())
    return x, caches, norms
```

## 💡 工程上真正要决定的三个量

**一、final norm 不是可选项。** Pre-LN 的流按 $\sqrt{L}$ 长，24 层就是 3.09 倍。没有 final norm，logits 的尺度随深度漂，同一套温度在 12 层和 48 层上含义不同。这一点是结构性的，与初始化无关。

**二、想做剪枝就选 Pre-LN，想每层出力平均就选 Post-LN。** 实测 Pre-LN 单层删除的破坏力从 55.2% 单调降到 18.9%，和写入份额同向——后段层在初始化时是「轻写入」；Post-LN 全程 50–62%，删哪层都一样疼，反过来说每层对流的贡献也是均匀的。

**三、梯度倾斜要用 warmup 或分层学习率接住。** Post-LN 首末层梯度差 3.07 倍、首层绝对值小 3.6 倍，如果两者给同一个 lr，浅层相对更新量小一个量级。这是 warmup 需要存在的一类理由（另一类是 Adam 第二步的方差），但「warmup 到底多长」只能从训练曲线里读，本文只给了初始化时刻的静态量级。

**测量边界写在最后一句里**：以上全部是随机初始化、$d=256$、24 层的静态测量，不是训练后的模型。训练会改变 $c$ 与 $\sigma$ 的分布（weight decay 与 LN 相互拉扯会把 $c$ 往下压），但「LN 放前面 → 流尺度不受控 → 必须 final norm」和「LN 放后面 → 每层一个 $1/\sigma$ 的雅可比 → 梯度沿深度倾斜」这两条不依赖初始化，它们是括号位置本身的推论。
