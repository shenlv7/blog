> 把用户数据里的姓名删掉，谁也认不出这是谁 —— 模型认得。
> 它不需要知道名字，只需要在训练时多看你的记录几遍，测试时的损失就会比没见过的样本低一点点。
> DP-SGD 只做两件事：把每条样本的梯度裁到固定长度，再按这个长度加噪声。剩下全是会计问题。

**读这篇要会**：小批量 SGD 的一步更新怎么写 / L2 范数 / 「相邻数据集」这个词——它指两份训练集只在一条记录上不同，后文所有敏感度都以它为单位。不需要 GPU，numpy 单机 3.4 秒跑完。

## 🎯 匿名化解决不了的问题

监管口径里最常见的脱敏做法是删字段：姓名、手机号、身份证号。删完之后这条记录还留在训练集里，模型的参数里还留着它的痕迹。差分隐私衡量的不是「记录里有没有个人信息」，而是**模型输出对单条记录的敏感程度**。

定义很干脆：随机机制 $M$ 满足 $(\varepsilon,\delta)$-差分隐私，当且仅当对任意两份只差一条记录的训练集 $D,D'$，以及任意输出集合 $S$：

$$\Pr[M(D)\in S]\le e^{\varepsilon}\Pr[M(D')\in S]+\delta$$

$\varepsilon$ 是「把这一条记录换掉，输出分布最多能差多少」的对数上界。$\varepsilon=1$ 意味着似然比最多 $e\approx2.72$ 倍，$\varepsilon=10$ 意味着两万倍。它不承诺攻击者一定失败，它承诺**攻击者从输出里能拿到的那点信息有上界，而且这个上界和攻击者的算法、辅助数据、算力都无关**。这一点很重要，后文会看到为什么不能拿「我跑了成员推断，AUC 只有 0.51」当验收。

## 🔬 机制：先给敏感度封顶，再按封顶值加噪

普通 SGD 的一步是 $\theta\leftarrow\theta-\eta\cdot\frac{1}{B}\sum_i g_i$，$g_i$ 是第 $i$ 条样本的梯度。问题在于：单条样本的梯度可以任意大。本次实验的数据里，逐样本梯度范数的中位数是 **1.325**，最大 **6.31** —— 是同一条数据、同一个模型，差了 4.8 倍。没有上界，就没法给「加多少噪声才够」定标。

DP-SGD 的裁剪把每条样本的贡献压进半径 $C$ 的球：

$$\tilde g=\frac{1}{B}\sum_{i=1}^{B}g_i\cdot\min\!\left(1,\frac{C}{\|g_i\|}\right)+\mathcal N\!\left(0,\left(\frac{\sigma C}{B}\right)^2 I\right)$$

裁剪后每条样本的贡献范数 $\le C/B$，所以整步更新的 **L2 敏感度恰好是 $C/B$**。高斯机制的结论是：敏感度为 $\Delta$ 时，加 $\mathcal N(0,(\sigma\Delta)^2 I)$ 就得到 $(\varepsilon,\delta)$-DP，$\sigma$ 与 $\varepsilon$ 的关系由 $\delta=\frac{4}{5}\exp(-(\sigma\varepsilon)^2/2)$ 反解（经典的 1.25 常数的近似形式）。注意噪声的尺度是**用 $C$ 定标的**，不是用梯度本身：$C$ 调小，噪声跟着小，但模型也被裁得学不动；$C$ 调大，噪声按同样比例涨。这是所有 DP 训练的第一个工程旋钮，Opacus 的默认值 1.0 就是这个量级的经验值，本次实验用预热一轮的中位数 1.325。

第二步是会计师。每步都加噪，步与步之间隐私会累积，而且每步只采样 $B/N$ 的样本（子采样放大），累积不能简单相加。本实验用子采样高斯机制的 RDP 界（Mironov 等人 2019 年的整数阶展开）：

$$\varepsilon_{\text{RDP}}(\alpha)=\frac{1}{\alpha-1}\log\sum_{k=0}^{\alpha}\binom{\alpha}{k}q^{k}(1-q)^{\alpha-k}\exp\!\left(\frac{k^2-k}{2\sigma^2}\right)$$

再对 $\alpha$ 取 $\min$ 并转成 $(\varepsilon,\delta)$。$\delta=10^{-6}$，$\alpha$ 从 2 取到 128。它是个保守界——换更紧的会计师，同一配置通常拿到更小的 $\varepsilon$。

## 📊 实测账单

逻辑回归，40 维，2000 条正常样本 + 8 条 6 倍范数的极端样本，batch 100，学习率 0.5，跑 60 轮（1204 步），测试集 4000 条。合成数据、单机 CPU，不是 GPU 上训 LLM 的实测。

三件事值得单独看。

**噪声在这个任务上先当了正则。** $\sigma=1$ 的准确率 0.899，比不加 DP 的 0.896 还高 0.3 个点；$\sigma=2$ 的 $\varepsilon=5.47$，准确率 0.896，和基线打平。也就是说，从 $\varepsilon=\infty$ 走到 $\varepsilon=5.5$，这段隐私几乎没花钱。$\varepsilon$ 的价格表是不对称的：前面 10 个 $\varepsilon$ 白送，最后 1.3 个（2.45 到 1.17）要花 2 个点。

**想靠少训练省钱，反而更贵。** 只跑 1 轮、$\sigma=1$：20 步，$\varepsilon=3.54$，准确率 0.870。同样 0.870 的精度，跑满 60 轮、$\sigma=8$ 只要 $\varepsilon=1.17$——便宜 3 倍。原因是 $\varepsilon$ 同时吃步数和噪声：砍掉 98% 的步数确实让总账变小，但留下来的精度也一起没了；而把噪声开大、把步数跑满，模型靠步数把噪声平均掉，精度和预算同时占优。这条对比说明「训练短 = 隐私便宜」是错的直觉，真正要调的是 $\sigma$ 与轮数的组合。

**batch 调大不自动变便宜。** $B$ 从 100 提到 500，步数从 1204 掉到 240，$\varepsilon$ 却从 15.58 涨到 38.11。子采样放大的强度取决于采样率 $q=B/N$：$q$ 从 0.05 升到 0.25，每步几乎等于全量参与，放大的好处消失，而每步的 RDP 消耗大幅上升。15 倍的步数差异没能抵掉这一点。要在大 batch 下拿回便宜，得同时降轮数（等价地，把 epoch 预算换成分母更大的数据集），不是只改 $B$。

## 💻 代码：能跑的那 20 行

```python
def train(sigma, B=100, epochs=60, C=None, seed=0):
    r = np.random.default_rng(seed)
    theta = np.zeros(D + 1)
    for _ in range(epochs * N // B):
        idx = r.integers(0, N, B)
        G = grad(theta, Xtr[idx], ytr[idx])          # 逐样本梯度，形状 (B, D+1)
        nrm = np.linalg.norm(G, axis=1, keepdims=True)
        G = G * np.minimum(1.0, C / (nrm + 1e-12))   # 裁剪：每条样本封顶 C
        g = G.mean(0)                                # 敏感度 = C / B
        if sigma > 0:
            g = g + r.normal(0.0, sigma * C / B, size=g.shape)
        theta -= LR * g
    return theta

def rdp_subsampled(q, sigma, alpha):                 # 子采样高斯的 RDP
    lg = [log(comb(alpha, k)) + k * log(q) + (alpha - k) * log(1 - q)
          + (k * k - k) / (2 * sigma * sigma) for k in range(alpha + 1)]
    m = max(lg)
    return (m + log(sum(exp(x - m) for x in lg))) / (alpha - 1)

eps = min(rdp_subsampled(B / N, sigma, a) * steps
          + log(1 / 1e-6) / (a - 1) for a in range(2, 129))
```

## 📉 0.51 这个数：攻击测不到 ≠ 有保证

上面那张表最后一列是成员推断的 AUC：把每条样本的损失取负当分数，在 2008 条训练样本和 4000 条没见过的样本之间算 Mann-Whitney AUC。**所有配置都在 0.510–0.518 之间**，连不加 DP 的基线也是 0.512。未训练模型上这个指标是 0.500，说明统计量本身没偏。

不加 DP 也只有 0.512，说明这个规模的模型**没有能力记住单条样本**：40 维、2000 条样本，训练损失 0.205、非训练 0.238，差距小到攻击者分不开。这不是「数据安全」，而是「模型太小」。同一种攻击在容量足够的模型上会显著偏离 0.5——Carlini 等人 2021 年那篇《Extracting Training Data from Large Language Models》之所以能从 GPT-2 里逐字取出训练文本，前提就是模型有容量把罕见串记下来。

所以 $\varepsilon$ 和 MI AUC 是两种东西：前者是**对所有攻击者成立的上界**，后者是**某一种攻击在某一份数据上实际拿到的优势**。拿后者当验收，会系统性地高估安全性——尤其当模型装不下要保护的东西时，它给出的结论是「不用做隐私保护」，而根据这个结论做的决定，会在换成大模型时原样保留下来。

## 🏗️ 三条工程规矩

**裁到多少：看分布，不看默认值。** 本实验里中位数 1.325、最大 6.31，$C$ 取 1.325 意味着约一半样本的梯度被等比缩小。裁剪引入的是**有偏**的梯度估计：它不改变方向（等比缩放），但会压掉长尾样本的步长，等价于给每个样本一个按范数反比的学习率。$C$ 取太小时，模型在大范数样本上学得更慢；取太大时，噪声按 $C$ 线性放大。预热一轮取中位数是 Opacus 文档里的常用做法，目的就是让这个取舍落在分布中间。

**$\varepsilon$ 别跟不同会计师比。** RDP 整数阶、RDP 分数阶（TensorFlow Privacy）、GDP（Google 的 dp_accounting）在同一配置下给出的 $\varepsilon$ 可以差出一截，因为它们对「攻击者能做什么」的假设不同。报告 $\varepsilon$ 时必须带 $(\delta, \text{会计师})$，否则那个数字没法比较。

**微调 LLM 时，$\varepsilon\le8$ 的现实价格是 batch 与轮数。** 本次实验的账在 2000 条样本、1204 步上成立；同样的噪声乘数搬到 6 万条样本、3 轮 epoch 上，$\varepsilon$ 会低一个量级，因为 $q$ 和步数都变小。反过来，小数据集全参数微调要在 $\varepsilon\le8$ 下完成，基本只能靠「大 batch + 少轮数 + LoRA 限参数」，这也是公开的 DP 微调工作普遍用 LoRA 的原因——它限制的不是梯度范数，而是可被单条样本改动的参数量。

## 💡 这篇的边界

合成二分类 + 逻辑回归，数字不能外推到 7B 模型的价格：容量、任务、数据分布都会改这条曲线，只有「$\varepsilon$ 由 $q$、$\sigma$、步数三者共同决定」这个结构是通用的。$\varepsilon$ 用的是整数阶 RDP 界，比紧会计师保守。成员推断只测了 loss 阈值一种攻击，换 LiRA 这类带影子模型的攻击，同样配置下 AUC 会更高——0.51 的含义是「这种攻击没找到信号」，不是「没有信号」。
