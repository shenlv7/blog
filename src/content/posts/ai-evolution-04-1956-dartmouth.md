> 一个学科的名字，通常不是被发现的时候起的，而是在要钱的时候起的。

**读这篇要会**：命题逻辑里的「替换」和「分离规则（modus ponens）」；广度优先搜索和启发式搜索的区别；能读懂用 Python 元组表示的语法树。不需要读过《数学原理》。

## 一、1955 年：没有领域，只有三个圈子的名字

1955 年，一群研究「会思考的机器」的人没有共同的出版物，没有共同的会议，也没有共同的词。他们分属三个圈层，各自用自己的行话称呼同一件事：

| 圈层 | 代表词 | 主要据点 | 方法偏好 |
|---|---|---|---|
| 控制论 | cybernetics | MIT、Macy 基金会系列会议 | 反馈、模拟量、生物类比 |
| 自动机理论 | automata studies | 普林斯顿、贝尔实验室 | 图灵机、形式语言、可计算性 |
| 复杂信息处理 | complex information processing | RAND、卡内基理工 | 符号操作、程序即理论 |

这三个词不是同义词，它们决定了你向谁投稿、跟谁申请经费、招什么样的学生。1951 年巴黎的控制论会议、1946 年起的 Macy 会议都在讨论「机器与心智」，都比达特茅斯早。所以把 1956 年那次会称作「第一届人工智能会议」，是一种事后追认，不是当时的事实。

技术上的卡点有两个，都在 1955 年是真的。

第一个是组合爆炸。当时的计算机能算弹道表、能跑天气预报，因为那些问题有连续的数学结构，可以用微分方程一步步逼近。但「证明一条定理」「下一盘棋」「翻译一句话」不是这种问题：它们的解空间是离散的、爆炸的。国际象棋的分支因子约 35，走 10 步就是 35¹⁰ ≈ 2.8×10¹⁵ 个局面；8 数码看似简单，9!/2 = 181,440 个可达状态，而 15 数码是 16!/2 ≈ 1.05×10¹³。穷举在这些数字面前不是慢，是不可能。

第二个是合法性。1955 年，计算机的名片是数值计算：ENIAC 算射表，IBM 701 做工程与商业运算。说「这台机器可以证明定理」，在当时的语境里属于越界主张——它需要的不只是一个程序，还需要一套说法，说明「智能」这件抽象的事凭什么能落到指令上。

两份力量在这里交汇：一群人有方法（符号操作），有问题（组合爆炸），缺一个共同的名字和一份共同的议程。1955 年 8 月 31 日，麦卡锡、明斯基、罗切斯特、香农交出了一份 17 页的打字稿，把这两样东西同时给了出来。

## 二、机制：把「证明」改写成「搜索 + 打分」

那份提案的第一句，就是这个学科此后七十年反复重写的一句话：

> We propose that a 2 month, 10 man study of artificial intelligence be carried out during the summer of 1956 at Dartmouth College in Hanover, New Hampshire. The study is to proceed on the basis of the conjecture that every aspect of learning or any other feature of intelligence can in principle be so precisely described that a machine can be made to simulate it.

「原则上可以被精确描述到足以让机器模拟」——这是一个可以被证伪的猜想，而不是一个定义。整个 1956 年的技术内容，就是往这个猜想上放第一批证据。

证据来自纽厄尔和西蒙。他们在 RAND 和卡内基理工做的程序叫 Logic Theorist（逻辑理论家），输入不是数字，是《数学原理》里的公式串。规则只有三条，全部是符号层面的：

1. **替换**：公式里的命题变元可以换成任意子公式。`p → (q → p)` 里的 `p` 换成 `(r → s)`，得到一条新公理实例。
2. **替换等价**：按等价式改写子公式，比如把 `p → q` 写成 `¬p ∨ q`。
3. **分离（detachment）**：已有 `A` 和 `A → B`，得到 `B`。

只有这三条，程序做的就是在一个无限增长的公式集合里找出通往目标的路径。这正是组合爆炸发生的现场：第 n 层可能派生的公式数按指数长，而目标公式往往要五六步才能到。

Logic Theorist 的做法不是穷举，是打分。它用两条启发式把候选砍掉：

- **相似度**：把候选公式与目标公式做结构比较，形状越接近越优先推进。差别不在语义，在树的轮廓——`(p → q) → (q → p)` 比 `p → (q → p)` 更像 `p → p`。
- **倒推**：把「证明 G」换成「找到一条能推出 G 的规则，再证明它的前提」。目标不变，但每一步的子目标更小。

这两条都不是定理，是经验判断。它们不保证找到解，只保证找到解之前少走弯路——这正是「启发式」（heuristic）在 1956 年的原始含义：来自希腊语「发现」，一种不保证最优、但让搜索可行的判断规则。

这里有一个容易被跳过的细节：为什么只有替换和分离不够。替换把一条公理展开成无穷多条实例，分离把两条公式合成第三条，两者都是「向上」的——只让公式集合变大，没有任何东西告诉程序该往哪个方向走。一条只有这两条规则的程序，等价于把所有可推导的公式按某个顺序排进队列，然后等目标自己浮出来。LT 的贡献不在于它多了哪条规则，而在于它在规则之上加了一个排序函数：候选公式先过一遍结构比较，最像目标的那几条先进队列。工程上这叫剪枝，1956 年的说法叫启发式。

### 启发式的价值可以精确到倍数量级

启发式最容易被写成玄学（「像人一样思考」），但它有一个硬指标：**同样的最优解，少展开多少状态**。下面这段代码把这件事做成可数的量。搜索空间换成 8 数码，因为它的状态数可以精确枚举，开销能被直接计数：

```python
GOAL = (1, 2, 3, 4, 5, 6, 7, 8, 0)          # 0 = 空格

def neighbors(s):
    z = s.index(0); r, c = divmod(z, 3)
    out = []
    for name, d in {'U': -3, 'D': 3, 'L': -1, 'R': 1}.items():
        if name == 'U' and r == 0: continue
        if name == 'D' and r == 2: continue
        if name == 'L' and c == 0: continue
        if name == 'R' and c == 2: continue
        t = list(s); t[z], t[z + d] = t[z + d], t[z]
        out.append(tuple(t))
    return out

def misplaced(s):     # 错位块数：每个错位块至少还要挪一次
    return sum(1 for i in range(9) if s[i] and s[i] != GOAL[i])

def manhattan(s):     # 曼哈顿距离：每个块到家的行列距离之和
    d = 0
    for i in range(9):
        v = s[i]
        if v:
            d += abs(i // 3 - (v - 1) // 3) + abs(i % 3 - (v - 1) % 3)
    return d

def astar(start, h):  # 评价函数 f = 已走步数 g + 估计剩余 h
    import heapq
    open_set = [(h(start), 0, start)]
    best = {start: 0}
    expanded = 0
    while open_set:
        _, g, s = heapq.heappop(open_set)
        expanded += 1
        if s == GOAL:
            return g, expanded
        for t in neighbors(s):
            if g + 1 < best.get(t, 10 ** 9):
                best[t] = g + 1
                heapq.heappush(open_set, (g + 1 + h(t), g + 1, t))
```

初始局面 `724 / 5.6 / 831`（最优解 20 步），本机 Python 3 实测：

```
A. 广度优先          最优解=20 步  展开状态= 55409  耗时=844ms
B. A*  h=错位块数    最优解=20 步  展开状态=  3667  耗时=123ms
C. A*  h=曼哈顿距离  最优解=20 步  展开状态=   283  耗时=11ms

B. A*  h=错位块数    展开量 = 广度优先的 1/15.1
C. A*  h=曼哈顿距离  展开量 = 广度优先的 1/195.8
```

三条路径的最优解都是 20 步，所以这不是「谁更聪明」的比较，而是「谁少做无用功」的比较：同一个答案，一个要摸 55409 个状态，一个只要 283 个。换一个更强的启发式（错位块数 → 曼哈顿距离），倍数从 15 涨到 196。

这段代码不是 Logic Theorist 的移植：它的搜索空间是拼图状态，LT 的搜索空间是公式串；1956 年也没有任何一份能这样逐项计数的开销报告，LT 的启发式是定性描述的，程序运行在 RAND 的 JOHNNIAC 上，单次运行以分钟到小时计。代码在这里的作用只有一个：证明「启发式」不是修辞，是一个可以写进日志的整数比。

有了这个刻度，1956 年的贡献就清楚了：它把「智能」从一种属性，改写成一次搜索；把「聪明」改写成「用更少的展开走到同一个答案」。这个改写在此后二十年里反复出现——1957 年纽厄尔和西蒙把它抽象成 GPS（通用问题求解器），1970 年代的专家系统把「启发式规则」直接做成产品。而在 1956 年那个夏天，它还是一个需要被说服的猜想。

## 三、产物：一个词、一笔打了折的钱、一份 38/52 的成绩单

**一份提案**。1955 年 8 月 31 日的打字稿共 17 页加扉页，四位作者各自带着机构署名：麦卡锡（达特茅斯学院数学系助理教授）、明斯基（哈佛大学初级研究员）、罗切斯特（IBM 信息研究部门经理）、香农（贝尔实验室）。提案请求洛克菲勒基金会资助 13,500 美元，细目包括每位非自带薪水的教员 1,200 美元（6 人共 7,200）、两名研究生各 700、旅费与房租约 2,400、秘书与复印 850 等。

提案里还有一条常被忽略的自述：香农与麦卡锡当时正在合编一本《自动机研究》（Automata Studies，普林斯顿大学出版社的 Annals of Mathematics Studies 系列），提案直接把这本书当作这个新领域的既有文献来引用。换句话说，1955 年的这批人手里已经有一本论文集、一批作者、一个正在成形的读者群；他们缺的不是内容，是把内容拢到一个名字底下的动作。

**一笔被砍的钱**。基金会生物与医学研究主任 Robert Morison 在 1955 年 11 月 30 日回信，只给 7,500 美元，且限定五周。他的理由写得很直白：

> I hope you won't feel we are being overcautious but the general feeling here is that this new field of mathematical models for thought, though very challenging for the long run, is still difficult to grasp very clearly. This suggests a modest gamble for exploring a new approach, but there is a great deal of hesitancy about risking any very substantial amount at this stage.

「一次适度的赌注」（a modest gamble）——这是美国最老牌的私人基金会在 1955 年给这个新领域的估值。今天回看，这个数字比会议本身更能说明 1956 年的处境：不是没人相信，是没人愿意押大。

**一份到场名单**。1956 年 5 月 26 日，麦卡锡通知基金会计划到场的 11 人：全程的明斯基、毕格罗、麦凯、索洛莫诺夫、霍兰德、麦卡锡本人；四周的香农、罗切斯特、塞尔弗里奇；前两周的纽厄尔与西蒙。实际到场远比名单松散：麦凯和霍兰德没来，莫尔代替罗切斯特待了三周，会期按索洛莫诺夫的笔记是 6 月 18 日到 8 月 17 日约八周，通常的说法是六周；每天到场的只有 3 到 8 人；全程待满的只有麦卡锡、明斯基、索洛莫诺夫三人。会后麦卡锡编了一份 47 人的「对人工智能问题感兴趣者」通讯录——那不是会议签到表，是一个领域的第一份邮件列表。

**一份成绩单**。会议期间最硬的产物是 Logic Theorist 的演示：它证明了《数学原理》第二章前 52 条定理中的 38 条。其中定理 2.85，程序给出的证明比罗素与怀特海原版更短。他们把这个新证明投给《符号逻辑杂志》（The Journal of Symbolic Logic），被退稿，理由是「一条初等定理的新证明不值得发表」——审稿人没有注意到，作者之一是一台机器。完整的技术描述以 RAND 报告的形式在 1956 年流传，随后发表。

**一个词**。会后没有正式论文集，麦卡锡承诺的会议报告也没有成书。留下来的东西里，传播得最远的是那三个词：artificial intelligence。麦卡锡后来解释过选词的理由，说得很朴素——要「把旗子钉在桅杆上」（nail the flag to the mast），因为他当时失望于《自动机研究》那本论文集里，真正处理「让机器表现出智能」的文章太少，需要给这批人一个更聚焦的名号。至于「避开控制论是为了不跟维纳打交道」这层动机，出自他人的转述与后人的整理，麦卡锡自己的说法偏向前者。

这里有一个常见的叙事需要打上标记：「那场会失败了」。说它没兑现承诺是准确的——提案里「一个夏天取得重大进展」没有发生，麦卡锡本人列过三条原因：基金会只给了一半的钱、与会者各有各的议程、到人和到的时间都太散。但说它「什么也没发生」就不准确：符号方法、有限领域系统（后来长成专家系统）、演绎与归纳的路线之争，这三条议程是在那八周里成形的，索洛莫诺夫的现场笔记记下了它们。一场会既可以被记成失败，也可以被记成起点，取决于你数的是产出还是承诺。

## 四、这个夏天真正改变的东西

1956 年之后，做这件事的人有了一个能填在申请书上的领域名、一个能发论文的圈子、一份 47 人的通讯录。这些不是学术装饰，它们决定了资源怎么流：有名字，基金会的评审才有对照的类别；有名字，大学才会设课程；有名字，学生才知道自己在学什么。

但更耐久的产出是那个改写：**智能 = 在符号空间里的搜索 + 一组把搜索引向目标的启发式**。它把「机器能不能思考」这个哲学问题，替换成一个工程问题——搜索空间多大、启发式多强、展开多少节点能到目标。这个替换带来了二十年的生产力，也带来了它的天花板：如果启发式是人手写的经验规则，那么系统的能力上限就是写规则的人的知识上限。这条路线走到 1980 年代会遇到自己的墙，那时会有另一批人回来问：这些规则能不能不从人脑子里取，从数据里学？

## 五、下一篇：1957，另一条路

就在达特茅斯那八周里，另一条路线已经在别处成型。1957 年，康奈尔航空实验室的罗森布拉特做出了感知机（Perceptron）：它不搜索符号，它调权重。前者把知识写成规则，后者把知识压进参数；前者靠启发式剪枝，后者靠数据纠错。
