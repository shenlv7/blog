> 同一份真实分布（Zipf，s=1.1，词表 2000），每代只拿上一代模型生成的 2000 个样本重训：
> 第 12 代词表从 **518** 缩到 **132**（−74.5%），对真实分布的 TV 距离从 **0.2236** 涨到 **0.4343**，
> 真实语料里 **34.2%** 的概率质量落在模型判为「概率 0」的类型上。
>
> 与此同时，两个最常用的健康指标全程报平安：top10 占比 **45.4% → 47.5%**，尾部（排名 1001–2000）质量 **5.89% → 5.95%**。
> 塌缩不是没发生，是它先把「类型」杀死，再把死掉的质量按比例分给幸存者，于是聚合统计量看不见。
>
> 对照组里每代掺回 2000 个真实样本，TV 反而降到 **0.1872**、词表稳定在 **726**；
> 只加 α=0.5 平滑，词表一个都没死，尾部质量却从 **20.6% 涨到 50.2%**、熵从 8.81 涨到 **10.48 bit**（均匀分布是 10.97）——
> 平滑没有阻止塌缩，它把「塌到少数类型」换成了「抹平成均匀分布」。
>
> 边界先钉死：这是**一元语言模型上的离散模拟**，不是 GPU 实测，也不是真实 LLM。它没有上下文、没有函数逼近误差，只测「有限采样 + 硬零计数」这一条机制单独能造成多大破坏。

**读这篇要会**：unigram 语言模型与最大似然（数频次除以总数）／总变差距离 TV 的定义／Zipf 分布的形状／「一个概率为 p 的类型在 n 次采样里被采到 0 次的概率约等于 $e^{-np}$」这个二项稀疏直觉。会 numpy，不需要 GPU。

## 🎯 塌缩到底先动哪个数

递归训练（recursive training）的定义很窄：第 $t+1$ 代模型的训练集**只**由第 $t$ 代模型的输出构成，真实数据被替换掉，不是叠加。

Shumailov 等人在 *Nature* 631, 755–759（2024-07-24，DOI 10.1038/s41586-024-07566-y）给出的现象描述是两步的：**先丢尾部**，模型质量向一个方差极小的点估计收缩；再往后整体漂移，生成分布里冒出原始模型永远不会产生的长尾（那些是累积下来的错误）。他们用高斯混合、VAE 和语言模型三条线做实验，结论一致。

本文不重复那篇的结论，只问一个更工程的问题：**如果塌缩正在发生，日常监控里哪个指标会先喊**？

答案是：几乎都不喊。因为塌缩的第一件事是让某些类型消失，而消失类型的质量会被幸存者按比例吃掉 —— 你在总量上看到的是一条平线。

## 🔬 实验设置

真实分布取 Zipf：$p_k \propto k^{-s}$，$s=1.1$，$V=2000$，按排名归一化。排名 1001–2000 记为尾部，真实质量 **5.68%**。

模型族是最小的一元模型：一个 2000 维概率向量，训练 = 数频次做最大似然，生成 = 按这个向量独立采样。每代采样 $n=2000$ 个 token，跑 12 代，重复 5 个随机种子取平均。

三组对照：

- **A 纯递归**：第 $t+1$ 代只用第 $t$ 代的 2000 个样本重训，无平滑。这是塌缩的干净版本。
- **B 累积真实数据**：每代在模型的 2000 个样本之外，再掺入 2000 个新鲜真实样本。对应 Gerstgrasser 等人（arXiv:2404.01413，NeurIPS 2024）主张的 accumulate 而非 replace。
- **C 只加平滑**：不掺真实数据，但把计数做加性平滑 $\alpha=0.5$。工程上最常见的「防塌缩」补丁。

六个指标：存活类型数、尾部质量、TV 距离、**真实分布落在模型判死类型上的质量**、top10 占比、熵。

## 📊 实测：指标集体失明的 12 代

A 组（5 seed 平均）：

| 代 | 存活词数 | 尾部质量 | TV | 真值落在死词上 | top10 占比 | 熵 (bit) |
|---|---|---|---|---|---|---|
| 1 | 518 | 5.89% | 0.2236 | 16.62% | 45.39% | 6.79 |
| 3 | 316 | 6.03% | 0.3112 | 22.70% | 46.15% | 6.43 |
| 6 | 215 | 6.69% | 0.3663 | 27.79% | 46.94% | 6.11 |
| 9 | 164 | 6.35% | 0.4041 | 31.46% | 48.06% | 5.84 |
| 12 | 132 | 5.95% | 0.4343 | 34.19% | 47.51% | 5.72 |

三件事值得单独说。

**第一，聚合指标是瞎的。** 词表掉了 74.5%，但 top10 占比只从 45.4% 挪到 47.5%（中间还上下跳），尾部质量从头到尾在 5.9%–6.6% 之间。原因是死的几乎都是低频类型，它们本来就只占一点点质量；这差不多的一点质量被幸存者按比例吃掉之后，尾部占比自然回到原地。**你盯着「尾部占多少」永远看不出尾部正在被删除**，因为被删的那部分质量没有消失，只是换了所有者。

**第二，能看见的是类型级指标。** 真值落在死词上的质量 16.6% → 34.2%，TV 0.2236 → 0.4343。三分之一以上的真实概率质量，模型给的响应是零 —— 这不是「生成得不够像」，是「这一块它根本没有」。

**第三，第 1 代 TV 的 0.2236 就是噪声下限。** 第 1 代模型是用**真数据**训的，它的偏差全部来自 $n=2000$ 在 2000 词表上的采样噪声。后面每一代要跟这条基线比，而不是跟 0 比。所有「塌缩多严重」的叙述都必须先扣掉这一项。

四个配置的第 1 / 12 代对比：

| 配置 | 词表 | 尾部质量 | TV | 熵 (bit) |
|---|---|---|---|---|
| A 纯递归 | 518 → 132 | 5.89% → 5.95% | 0.2236 → **0.4343** | 6.79 → 5.72 |
| B 累积真实数据 | 518 → 726 | 5.89% → 5.70% | 0.2236 → **0.1872** | 6.79 → 6.93 |
| C 平滑 α=0.5 | 2000 → 2000 | 20.59% → **50.16%** | 0.2731 → 0.7223 | 8.81 → 10.48 |

B 组的 TV 比第 1 代还低 —— 因为数据量翻倍，采样噪声下降。累积真实数据不是「减缓塌缩」，它是把误差钉在基线以下（Gerstgrasser 等人对线性模型给出了有限上界，与这里的稳态表现一致）。

C 组最值得看：**词表一个都没死**，通不过「塌缩」的表层检查。但尾部质量从 20.6% 涨到 50.2%，top10 占比从 30.4% 跌到 2.9%，熵 8.81 → 10.48，已经逼近均匀分布的 10.97。TV 0.7223 甚至比「均匀分布对真实分布」的 0.6953 还高（104%）。它没有塌到少数类型上，它塌到了**均匀**上。

## 🧩 机制：灭绝线、自加速的消失、平滑的解析解

**灭绝线。** 一个概率为 $p$ 的类型，在这一代的 $n$ 次采样里一次都没出现的概率是

$$P(\text{灭绝})=(1-p)^n\approx e^{-np}$$

所以 $np \lesssim 1$ 就是死亡区，也就是 $p \lesssim 1/n = 5\times10^{-4}$。在这份真实分布里，落在 $p < 1/2000$ 的类型有 **1801 个**，合计质量 **20.52%** —— 真实语料里五分之一的质量，正好躺在单次采样的分辨率之外。这解释了 A 组第 1 代的 16.6%：一次采样就已经把一大批罕见类型抹成零。

**为什么不会自己停。** 类型死掉后，它的质量被幸存者按比例吸收，幸存者的 $p$ 上升，下一代的存活率也上升。于是衰减减速（−26% → −17% → −11%/代）却不收敛：跑到第 40 代，存活 **55** 个、TV **0.5725**、熵 4.83 bit，而 top10 占比反而回升到 57.35%。塌缩收敛到一个「小核」，不是收敛到一个点 —— 在这个核内，模型是自洽的、稳定的、看起来毫无异常的。

**平滑的解析解。** 加性平滑后的更新是线性的：

$$p_{t+1}(i)=\frac{n\,p_t(i)+\alpha}{n+\alpha V}=\underbrace{\frac{n}{n+\alpha V}}_{0.6667}p_t(i)+\frac{\alpha V}{n+\alpha V}\cdot\frac{1}{V}$$

$n=2000,\ \alpha=0.5,\ V=2000$，收缩因子 $0.6667$：每代把「偏离均匀」乘 0.667，11 代后只剩 **1.16%**。这就是 C 组熵一路涨到 10.48 的原因 —— 它不是在学习分布，它是在做固定比例的向均匀收缩。**平滑保证每个类型活下来，代价是保证每个类型都活得不像自己。**

## 🏗️ 工程含义

1. **区分 replace 和 accumulate。** 递归管线的默认行为是替换（新数据覆盖旧数据），这是塌缩最快的形态。合成数据要带血缘和「真实/合成」标记，训练时按固定比例把真实数据锚进每一代，而不是只在第一代用一次。
2. **平滑不是解药，是另一种失真。** α 让罕见类永不归零，但会把长尾抹平；如果下游依赖长尾（实体链接、罕见语言、长尾失败模式），抹平比删除更危险，因为所有聚合指标都是绿的。
3. **监控口径要下沉到类型级。** 至少三个：去重类型数的世代变化；留出真实样本中被模型判为概率 $<\epsilon$ 的比例（本文的「真值落在死词上」）；以及分布距离（TV / MMD）对着**同尺寸真实样本的基线**看。
4. **采样截断会叠加同形状的收缩。** 如果生成时只用 top-p / top-k，等于在重训前又加一层向头部收缩，和 α 平滑的公式同一形状，只是系数不同。这条本文没单独跑，别把它当实测数字引用。

## 💻 代码

核心 40 行（`numpy`，0.6 秒跑完全部三组）：

```python
import numpy as np

V, S, N, GENS = 2000, 1.1, 2000, 12          # 词表 / Zipf 指数 / 每代采样量 / 代数
TRUE = 1.0 / np.arange(1, V + 1) ** S
TRUE /= TRUE.sum()

def mle(counts, alpha=0.0):                   # alpha=0 就是纯数频次，没见过的类型概率为 0
    c = counts + alpha
    return c / c.sum()

def tv(p, q):
    return 0.5 * np.abs(p - q).sum()

def run(alpha=0.0, accumulate_real=False, seed=0):
    rng = np.random.default_rng(seed)
    p = mle(np.bincount(rng.choice(V, size=N, p=TRUE), minlength=V), alpha)
    rows = []
    for g in range(1, GENS + 1):
        if g > 1:                             # 第 1 代用真数据，之后只用上一代的样本
            x = rng.choice(V, size=N, p=p)
            if accumulate_real:
                x = np.concatenate([x, rng.choice(V, size=N, p=TRUE)])
            p = mle(np.bincount(x, minlength=V), alpha)
        rows.append((g, int((p > 0).sum()), p[1000:].sum(), tv(p, TRUE),
                     TRUE[p == 0].sum(), np.sort(p)[-10:].sum(),
                     -(p[p > 0] * np.log2(p[p > 0])).sum()))
    return rows

for name, kw in (('A 纯递归', {}), ('B 累积真数据', {'accumulate_real': True}),
                 ('C 平滑 α=0.5', {'alpha': 0.5})):
    runs = [run(seed=s, **kw) for s in range(5)]
    alive, tail, dist = (np.mean([r[-1][i] for r in runs]) for i in (1, 2, 3))
    print(f'{name} 第12代：存活 {alive:.0f}  尾部 {tail:.2%}  TV {dist:.4f}')
```

## 💡 结论

递归训练的第一阶段不是「生成变差」，是**类型死亡**：$p \lesssim 1/n$ 的类型在一代之内就被采样噪声抹成零，之后永久缺席，而它们的质量被幸存者接管，于是总量、top10 占比、尾部占比全都看不出问题。真正记录破坏的是类型级统计量 —— 这份 2000 词表的实验里，12 代丢掉 74.5% 的类型、34.2% 的真实质量落到零概率区，而两个最常被引用的健康指标最大只动了 2.1 个百分点。

一元模型没有上下文，真实 LLM 的塌缩还叠加函数逼近误差和组合误差，规模效应也不同。但「有限采样 + 硬零计数」这一条机制单独就足够造成这个量级的损失 —— 想靠加大采样量解决它，$n$ 每翻十倍只是把灭绝线从 $p<1/n$ 往下挪一个数量级，而真实语料的尾部通常跨越三四个数量级。真正把它钉住的是真实数据的锚，不是更大的 $n$，也不是更小的 $\alpha$。
