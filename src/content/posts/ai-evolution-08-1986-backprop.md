> 一个隐藏单元错了，你不知道是它自己错了，还是它上游的输入错了，还是下游把它的正确输出用错了。

**读这篇要会**：多元链式法则 / 矩阵乘法与逐元素求导 / sigmoid 的导数 / 「梯度指向函数上升最快的方向」这一句的意思。

---

## 一、卡点：1969 年之后，隐藏层没有老师

1969 年 Minsky 和 Papert 在《Perceptrons》里证明了单层感知机做不了 XOR（第 06 期讲过这段，以及这个结论被误读成「神经网络完了」的过程）。结论本身不复杂：单层感知机每个输出单元是输入的线性组合过一个阈值，它能分的类在输入空间里是一条直线切两半；XOR 的四个点排成对角，一条直线切不开。

结构上的出路当年就很清楚——中间加一层。输入不再直接连到输出，先连到一组隐藏单元，隐藏单元再连到输出。这样一来，输出层仍然只做线性切分，但切的不再是原始输入空间，而是隐藏层造出来的新空间；XOR 在这个新空间里可以被一条直线切开。这个想法在 1960 年代就被反复提出，多层网络的表达能力在理论上也没有争议。

真正卡住的是另一件事：**怎么训练**。

单层感知机的学习规则简单到可以手算。给定输入 x 和期望输出 t，如果输出错了，就按 `w ← w + ε(t − o)x` 调整权重。规则成立的依据是：输出错了，而且每个权重对输出的影响是已知的，那就朝减小误差的方向推一把。

隐藏层把这条链断掉了。隐藏单元没有期望输出。训练集只告诉你「输入这四个比特，应该输出这个」，它没告诉你中间那三个单元各自应该输出什么。没有目标值，就没有「误差」，也就没有方向可以推。这个问题后来有个专门的名字：**信用分配（credit assignment）**——最终误差出现了，该记在哪个权重头上。

1970 到 1985 年，绕开它的办法只有三类，代价都很难看。

| 办法 | 怎么做 | 代价 |
|---|---|---|
| 随机搜权重 | 反复采样权重，留误差小的 | 参数量一上去就穷举不动 |
| 给隐藏单元指定目标 | 枚举隐藏层的目标模式，逐个试 | 隐藏层有 3 个二值单元就有 8 种目标组合，每层再乘 |
| 只训练最后一层 | 隐藏层固定随机，只学输出层 | 等价于随机特征，XOR 这类任务上不稳定 |

第一类的量级可以算：后面会跑一个 8-3-8 的网络，输入到隐藏 24 个权重、隐藏到输出 24 个权重、6 个偏置，共 54 个参数。就算每个参数只取 3 个档位，也要搜 3⁵⁴ ≈ 5.8×10²⁵ 种组合。第三类的问题是表达能力被扔掉了——隐藏层学不到东西，深层结构就等于白加。

所以 1970 年代的神经网络研究是少数派。符号主义在做专家系统，钱和人都往那边走（第 07 期）。连接主义这边能拿出来的东西是 Hopfield 网络（1982）和玻尔兹曼机（1985），数学上漂亮，但训练慢到没法用在稍微大一点的问题上。

## 二、机制：误差沿着链式法则走回去

1986 年 10 月 9 日，Rumelhart、Hinton、Williams 在 Nature 上发了一篇 4 页的短文，《Learning representations by back-propagating errors》。收稿日期 1986 年 5 月 1 日，接受日期 7 月 31 日。

它解决信用分配的方式，是把「没有目标值」这件事直接绕过去：**不给隐藏单元定目标，只要求它对下游的总误差负责。**

先把网络写成函数。输入 x，隐藏层输出 `h = σ(W₁x)`，输出层 `o = σ(W₂h)`，σ 是 sigmoid。误差取平方和的一半：

```text
E = ½ · Σ_k (t_k − o_k)²        t 是目标，o 是输出
```

对输出层的权重求导，链式法则走三步：平方 → sigmoid → 线性组合。sigmoid 的导数是 σ′(z) = σ(z)(1 − σ(z))，正好可以用已经算出来的输出值表示，不用额外存东西。于是输出层每个单元的「责任」是：

```text
δ_k = (o_k − t_k) · o_k · (1 − o_k)
```

到这里还是单层感知机的老套路。关键在下一步。隐藏单元 j 没有目标值 t_j，但它连着下游每一个输出单元，而每个输出单元的 δ 已经算出来了。把下游所有单元的责任按其连接权重加权求和，就得到隐藏单元 j 的责任：

```text
δ_j = o_j · (1 − o_j) · Σ_k  w_kj · δ_k
```

这个式子是整篇论文的核心。翻译成人话：**隐藏单元不知道正确答案是什么，但它知道自己往下游送的东西在多大程度上害了别人。** 下游每一个单元的不满，按连接强度折算回来，加总就是它的账。

权重更新就用 δ 乘以输入，再加上一个动量项：

```text
Δw_ij(t) = −ε · δ_j · o_i + α · Δw_ij(t−1)
```

第一项是标准梯度下降，第二项是 1986 年那篇论文里的做法——保留上一次的更新方向，让它在误差面上有一点惯性，同时抑制来回震荡。论文用的参数是 ε = 0.01、α = 0.9 这一档。

整个算法的代价是可以直接数的：一次前向传播算出所有激活值，一次反向传播把 δ 从输出层逐层乘回去，两次传播的浮点运算量同一个量级。结果是拿到**全部** W 个参数的导数，总成本约等于 2 次前向。

对比一下如果不用这个式子，怎么算导数：对每个参数单独做一次中心差分，需要 2 次前向。W 个参数就是 2W 次前向。这就是为什么「往回传」不是一个数学技巧，而是这个东西能不能在 1986 年的机器上跑起来的分界线。

下面是核对这个推导的代码，也是后面所有实验的骨架：

```python
def grads(self, X, Y):
    n = X.shape[0]
    H, O = self.forward(X)                     # h = σ(xW1+b1), o = σ(hW2+b2)
    dO = (O - Y) * O * (1.0 - O)               # δ_k = (o-t)·o(1-o)，输出层
    gW2 = H.T @ dO / n
    gb2 = dO.mean(axis=0)
    dH = (dO @ self.W2.T) * H * (1.0 - H)       # δ_j = o_j(1-o_j)·Σ_k w_kj δ_k，隐藏层
    gW1 = X.T @ dH / n
    gb1 = dH.mean(axis=0)
    return gW1, gb1, gW2, gb2, O
```

用中心差分核对同一组权重上的解析梯度，`h = 1e-6`：

```
解析梯度  dE/dW1 =
 [[-0.002247 +0.001911 -0.000059]
 [-0.002773 +0.001570 +0.000246]]
数值梯度  dE/dW1 =
 [[-0.002247 +0.001911 -0.000059]
 [-0.002773 +0.001570 +0.000246]]
最大绝对误差 = 1.49e-11
```

误差在 1e-11 量级，比单精度训练能容忍的 1e-4 低了五个数量级。反向传播算出来的就是真正的梯度，不是某种近似。

## 三、实测：公式对，不等于训得出来

公式对，不等于能训出东西。下面五个实验都在本机跑，纯 numpy，无 GPU，脚本在文末。

### 1. XOR 学得会，但不保证每次

2-2-1 网络（两个输入、两个隐藏、一个输出），ε = 0.5、α = 0.9，十个随机种子各跑 8000 轮，收敛判据是四个样本的输出与目标差都小于 0.05：

```
seed 0: 第 3069 轮收敛  输出 = [0.043 0.95  0.961 0.038]
seed 1: 第 1721 轮收敛  输出 = [0.05  0.955 0.955 0.048]
seed 2: 第 6306 轮收敛  输出 = [0.05  0.959 0.955 0.045]
seed 3: 第 2653 轮收敛  输出 = [0.045 0.957 0.95  0.04 ]
seed 4: 第 1443 轮收敛  输出 = [0.05  0.955 0.955 0.049]
seed 5: 第 5957 轮收敛  输出 = [0.045 0.95  0.957 0.04 ]
seed 6: 8000 轮未收敛  输出 = [0.148 0.76  0.76  0.363]
seed 7: 第 2948 轮收敛  输出 = [0.043 0.95  0.961 0.038]
seed 8: 第 2695 轮收敛  输出 = [0.05  0.954 0.954 0.049]
seed 9: 第 2678 轮收敛  输出 = [0.05  0.954 0.954 0.049]
收敛 9/10，平均 3274 轮，最慢 6306 轮，最快 1443 轮
```

16 年前被判死刑的 XOR，两个隐藏单元就解决了。十个种子里最快和最慢差 4 倍以上，seed 6 在 8000 轮预算内没走出去——输出停在 0.148 / 0.76 / 0.76 / 0.363，符合 XOR 的形状但幅度不够。这个状态下误差还在下降，只是太慢，不能据此说是局部极小；能说的是，1986 年那篇论文报告的成功率从来不是 100%，初始化和学习率决定了它走到哪个盆地。

### 2. 没有非线性，加层等于没加

这一条同样可以跑出来。把隐藏层的 sigmoid 换成恒等映射，其余参数、更新公式、训练轮数都不动，同样 20000 轮：

```
训练后输出 = [0.5 0.5 0.5 0.5]
MSE = 0.250000   两个隐藏单元实际是输入的线性变换：
  h = xW1，W1 的秩 = 1，两层复合等价于单个 2x1 线性映射
```

误差停在 0.25，和完全没有隐藏单元的 2-1 网络一模一样——多出来的两个单元一个比特的信息都没多提供。原因是恒等式而不是训练不足：`W₂(W₁x) = (W₂W₁)x`，两个线性映射复合还是一个线性映射，隐藏层只是把输入换了个坐标，表达能力不多一分。sigmoid 这类可微非线性因此不是审美选择，它是算法能成立的前提；同理，δ 公式里那个 `o(1−o)` 因子，就是非线性的导数。

### 3. 全零初始化，隐藏单元会塌成一个

把 2-2-1 的权重全部初始化为 0，其他参数不变，跑 8000 轮：

```
8000 轮后 MSE = 0.1250（正常初始化收敛时约 2e-3）
两个隐藏单元对 4 个输入的激活：
  unit0 = [0.5 0.5 0.5 0.5]
  unit1 = [0.5 0.5 0.5 0.5]
  两者最大差 = 0.00e+00  -> 完全共线，等于只有一个隐藏单元
```

原因在公式里：两个隐藏单元初始权重相同，收到的输入相同，算出的 δ 也相同，更新量相同——它们永远保持一模一样的函数。这不是训练不足，是**对称性没有破**。1986 年的实现靠小随机数初始化解决（本机用 U(−0.3, 0.3)），用零初始化时，隐藏层的存在感为零。

这条坑至今还在：所有框架默认的随机初始化，防的就是这个。

### 4. 隐藏单元真的会自己长出表示

论文标题里的 "learning representations" 指的就是这件事：没人告诉隐藏层该编码什么，它自己长出了有用的中间表示。最小的可验证版本是「编码器」——输入和输出相同，中间只留比输入更窄的一层，网络必须学会压缩再还原。

8 位输入、3 个隐藏单元、8 位输出，8 个互相重叠的移位模式，训练到最大绝对误差小于 0.1：

```
994 轮后最大绝对误差 = 0.09996，MSE = 9.05e-03
学到的 3 维码（8 个模式是相邻位移，码字也排成一条连续路径）：
  [1 1 0 0 0 0 0 0] -> (0.00, 0.91, 0.99)
  [1 1 1 0 0 0 0 0] -> (0.00, 0.34, 1.00)
  [0 1 1 1 0 0 0 0] -> (0.44, 0.01, 1.00)
  [0 0 1 1 1 0 0 0] -> (1.00, 0.00, 0.98)
  [0 0 0 1 1 1 0 0] -> (1.00, 0.01, 0.13)
  [0 0 0 0 1 1 1 0] -> (1.00, 0.68, 0.07)
  [0 0 0 0 0 1 1 1] -> (0.54, 1.00, 0.01)
  [0 0 0 0 0 0 1 1] -> (0.13, 1.00, 0.16)
码字之间的最小 L1 距离 = 0.56（没有两个模式共用同一个码）
```

8 个 8 位模式被压进 3 个数，还原误差 0.1 以内。三个隐藏单元不是各自记住一个模式，而是把「位移了多少格」这件事编码成一条连续的路径：相邻模式在码空间里也相邻。这种表示是梯度下降自己找到的，没有任何一项损失函数要求它保持相似性。

这个实验的原始版本出自 PDP 书第 8 章，论文里引用的是 Ackley、Hinton、Sejnowski 1985 年的编码器工作。

### 5. 103 倍

最后一个数字，回答「为什么 1986 年才有人把它跑起来」。50-40-10 的全连接网，批大小 1000，2400 个参数：

```
解析梯度（一次前向 + 一次反向）：20 次耗时 0.134s
中心差分：每个权重要 2 次前向，全量外推 ≈ 13.77s
比值 ≈ 103x
```

同一台机器、同一批数据，反向传播比逐参数差分快两个数量级。这是纯 numpy 在本机的测量，不是当年硬件的实测；但它说明的量级关系与硬件无关——反向传播的成本是 O(一次前向)，差分的成本是 O(参数量 × 一次前向)。

## 四、产物：一篇 4 页的论文，两卷书，和一个能读字母的网

**论文本身**：Nature 323 卷 533–536 页，1986 年 10 月 9 日。按 NASA ADS 的记录，这篇 4 页的短文被引用约 5.3 万次。

**两卷书**：同年 MIT Press 出了《Parallel Distributed Processing: Explorations in the Microstructure of Cognition》，Rumelhart 与 McClelland 主编，第一卷 Foundations、第二卷 Psychological and Biological Models。第 8 章《Learning internal representations by error propagation》是反向传播的系统版本，第 18 章用同一个算法训练英语动词过去式，模型自己产生了 `go → goed` 这类过度泛化错误——这是人类儿童学语言时的典型错误，而模型没有被告知任何规则。

**家族树实验**：论文里最能说明「隐藏层长出表示」的不是 XOR，是这个任务。输入是 24 个人的身份加上 12 种亲属关系，输出是被问的那个人。24 个人分属两棵同构的家族树（一棵英国人、一棵意大利人，结构完全一样，只是人名不同），一共 104 个「某人 + 关系」的有效组合。网络是五层：24 个人物输入和 12 个关系输入各自先接一组 6 个单元，汇到中央 12 个单元，再到 6 个，最后是输出层。训练只给 100 个组合，剩下 4 个留作测试，1500 轮后四个全对。

关键在隐藏单元学到了什么：第二层的 1 号、2 号、6 号单元分别对应国籍（英国/意大利）、辈分、家族分支。网络从没被告知这三件事，是它自己在 24 个身份标签里发现的——因为只有按这三条轴组织，亲属关系才能用少量「微推理」（中年人的父亲是老年人、意大利人的父亲是意大利人）算完。

**下游产物**：1987 年 Sejnowski 和 Rosenberg 的 NETtalk，用反向传播让网络把英文文本读出来。输入是当前字母加上前后各三个字母（共 7 个字母位置），输出是 21 个发音特征加 5 个重音与音节边界特征，中间 80 个隐藏单元。它没有背单词表：训练后遇到没见过的词也能读对大部分，这是「学到的规则能泛化」第一次在语音任务上被公开演示。1989 年 LeCun 在贝尔实验室用同样的算法训练卷积网络识别手写邮编，把反向传播推到了第一个真实商业场景。

## 五、归因与边界

**谁先发明的，这件事有争议，而且争议不小。** 1960 年 Kelley 在控制论里给出过伴随法的前身；1970 年芬兰赫尔辛基大学的研究生 Seppo Linnainmaa 在硕士论文里给出了反向模式自动微分的完整算法和 FORTRAN 代码（论文用芬兰语写，第 58–60 页；1976 年在 BIT 16:146–160 发表英文版）；Werbos 1974 年的哈佛博士论文里有相关章节，但按 Schmidhuber 的考证，神经网络语境下的首次应用是 Werbos 1982 年那篇 IFIP 论文，而不是 1974 年的学位论文——「Werbos 1974 年就发表了反向传播」这个常见说法本身站不住。1985 年 Parker 和 LeCun 也各自独立给出过等价形式。

1986 年那篇的贡献不是发明公式，是两件别的事：把它做成了可复现的实验结果，以及把它写进了一本别人能照着实现的教科书。一个算法有没有被用起来，往往取决于第二件事。

**作者自己的话**：论文最后一段写明，这套程序按当时的形态，并不是大脑学习的一个可信模型。心理学上的宏大解读是后来的事，不是这篇 4 页短文的结论。

**它没有解决的事**：1986 年的实验规模是几十个单元、几十到几百个样本，全部跑在串行机器上。反向传播在数学上是通的，在 1986 年的硬件上却训不出深网络——层数一多，误差往回传的时候会指数级缩小，浅层几乎收不到信号。这件事要等到 2012 年 GPU 和数据规模追上来才真正解决（第 12 期）。1980 年代后期到 1990 年代初的第二次退潮，直接原因是 LISP 机器市场崩盘和专家系统的维护成本失控，不能全算在这套算法头上。
