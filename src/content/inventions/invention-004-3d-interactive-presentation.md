## 一、要解决什么问题？

传统PPT和流程图的三大痛点：

1. **静态** — 内容一成不变，观众被动接收
2. **平面** — 复杂关系难以在2D空间表达
3. **无交互** — 看完就忘，没有参与感

## 二、核心方案：文西的演示工坊

### 2.1 产品定位

一句话：**用AI把你的想法变成可交互的3D演示空间**

- 输入：一段文字描述 / 大纲 / 思维导图
- 输出：可交互、可分享的3D演示场景
- 核心卖点：AI生成 + 3D交互 + 一键分享

### 2.2 用户旅程

```
[打开网页] → [输入想法] → [AI生成3D场景] → [微调编辑] → [分享链接]
     │              │              │              │            │
   30秒          1分钟          自动           拖拽调整      一键
```

### 2.4 核心功能模块

#### 模块一：3D 场景引擎

```typescript
// 节点定义
interface SceneNode {
  id: string;
  type: 'topic' | 'step' | 'data' | 'media';
  position: [number, number, number]; // 3D坐标
  content: {
    title: string;
    description?: string;
    icon?: string;
    color?: string;
  };
  connections: string[]; // 关联节点ID
  children?: SceneNode[]; // 子节点
}

// 场景定义
interface Scene3D {
  id: string;
  title: string;
  nodes: SceneNode[];
  camera: {
    default: [number, number, number];
    animations: CameraAnimation[];
  };
  theme: 'space' | 'neon' | 'minimal' | 'nature';
}
```

#### 模块二：交互系统

六大交互模式：

| 交互 | 触发方式 | 效果 |
|------|----------|------|
| 🔍 聚焦 | 点击节点 | 相机飞向节点，展开详情卡片 |
| ✨ 高亮 | 悬停节点 | 关联节点高亮，无关节点淡化 |
| 🖐️ 拖拽 | 长按拖动 | 自由调整节点位置 |
| 🎬 漫游 | 播放按钮 | 相机按路径自动巡游 |
| 🔗 跳转 | 点击链接 | 跳转到关联节点/外部URL |
| 📱 响应 | 手指捏合 | 移动端缩放旋转 |

```typescript
// 交互类型
type InteractionType = 
  | 'click'      // 点击展开详情
  | 'hover'      // 悬停高亮关联
  | 'drag'       // 拖拽重新排列
  | 'scroll'     // 滚动切换视角
  | 'gesture';   // 手势缩放旋转

// 交互事件
interface InteractionEvent {
  type: InteractionType;
  target: string; // 节点ID
  action: () => void;
}
```

#### 模块三：AI 生成引擎

AI生成流程详解：

```
用户输入: "团队协作的五个关键"
        ↓
[Step 1] LLM 分析 → 提取主题 + 子主题 + 关系
        ↓
[Step 2] 结构化 → 生成节点树 JSON
        ↓
[Step 3] 布局算法 → 球形/树形/力导向布局
        ↓
[Step 4] 主题匹配 → 根据内容选择视觉风格
        ↓
[Step 5] 动画编排 → 生成入场/切换动画序列
        ↓
输出: 完整可交互的3D演示场景
```

#### 模块四：视觉主题系统

| 主题名 | 风格 | 适用场景 |
|--------|------|----------|
| 🚀 星际 | 深色背景 + 星云粒子 | 科技/未来感 |
| 🌿 自然 | 绿色渐变 + 柔和光晕 | 教育/健康 |
| 💡 极简 | 白色背景 + 线条节点 | 商务/汇报 |
| 🌃 霓虹 | 黑底 + 霓虹发光 | 潮流/创意 |
| 🏛️ 展厅 | 灰色调 + 物理光照 | 产品展示 |

```typescript
// AI 生成流程
async function generatePresentation(prompt: string): Promise<Scene3D> {
  // Step 1: 文本分析 → 结构化内容
  const structure = await analyzeText(prompt);
  
  // Step 2: 结构 → 节点树
  const nodeTree = buildNodeTree(structure);
  
  // Step 3: 节点树 → 3D 布局
  const layout = autoLayout3D(nodeTree);
  
  // Step 4: 应用主题和动画
  const scene = applyTheme(layout, selectTheme(structure));
  
  return scene;
}
```

### 2.5 技术选型

| 技术 | 用途 | 优势 |
|------|------|------|

## 三、MVP 最小可行产品

### MVP 范围定义

**目标**：一个能用的 demo，输入文字 → 生成3D演示 → 可交互浏览

**砍掉的**：用户系统、云端保存、多人协作、自定义主题

### Phase 1：3D 基础引擎 ✅ [当前阶段]
- [x] Three.js 场景搭建
- [x] 基础节点渲染（球体 + 文字标签）
- [x] 节点连线（曲线管道）
- [x] 相机控制（轨道控制器）
- [x] 环境光照 + 背景

### Phase 2：交互系统
- [ ] 点击节点 → 相机飞向 + 展开详情
- [ ] 悬停节点 → 高亮关联、淡化无关
- [ ] 播放模式 → 自动漫游巡览
- [ ] 键盘快捷键（空格播放、ESC重置）

### Phase 3：AI 集成
- [ ] 文本输入框
- [ ] LLM 调用 → 结构化 JSON
- [ ] JSON → 3D 节点树自动渲染
- [ ] 4种布局算法切换

### Phase 4：打磨分享
- [ ] 响应式适配（桌面 + 移动）
- [ ] 导出截图/GIF
- [ ] 生成分享链接（URL 编码场景数据）
- [ ] 嵌入代码生成（iframe）

## 四、应用场景

1. **产品发布会** — 立体展示产品特性
2. **技术分享** — 3D架构图、流程图
3. **教学课件** — 沉浸式学习体验
4. **项目汇报** — 数据可视化看板
5. **头脑风暴** — 3D思维导图

## 五、差异化优势

| 对比 | 传统PPT | 3D Presenter |
|------|---------|--------------|
| 展示形式 | 2D平面 | 3D空间 |
| 交互性 | 无/弱 | 强交互 |
| 制作难度 | 低 | AI辅助降低门槛 |
| 分享方式 | 文件传输 | 链接/嵌入 |
| 观众体验 | 被动接收 | 主动探索 |
